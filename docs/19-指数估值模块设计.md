# docs/19 · 指数估值模块（债指之外的指数型基金）

> **地位**：本文件是「指数估值」页签的唯一口径与维护说明（v5.22 起）。
> 债指（`indexfund.py` / docs/17）与三池主动评分**不受本模块影响**；本模块只增发
> `data.js` 的 `eq_index` 键与一个页签，不改动 `funds[]` / `pools{}` / 筛选与评分链。
> 版本：模块 `EQ_INDEX["version"] = v1.0`；产物 `MODEL_VERSION = v5.22`。

## 〇、一句话

**指数卡=指数，不是基金**：卡片只展示估值档位/历史分位/主指标现值与「可选基金 N 只 · 最低综合费率」；
详情页展示估值口径、PE/PB 双分位、近 5 年走势，并列出同指数 **5 只低费率场外基金（含 A/C 份额）**。

## 一、范围与拍板（2026-10-29 用户确认）

| 项 | 决定 |
|---|---|
| 本期范围 | **只做债指之外的指数型基金**（`指数型-股票` + `指数型-海外股票`）；债指 tab 与三池不动 |
| 指数覆盖 | 雪球基金·指数估值提供的 **63 个主流指数**（宽基/行业/策略/海外） |
| 档位口径 | 按**该指数自身历史分位**切五档；另显同类型（宽基/行业/策略/海外）横向排名 |
| 排序 | 指数页签组内**按估值分位升序（越便宜越靠前）** |
| 基金清单 | **5 只、含 A/C 份额、按综合费率升序**；暂停申购沉底 |
| 基金筛选 | **剔除场内 ETF、剔除指数增强型**（保留 ETF 联接/LOF/普通场外指数基金） |
| 卡片 | 不放具体基金名称/代码；保留「可选基金 N 只 · 最低综合费率」 |
| 无估值指数 | **不展示**，不拿价格分位冒充估值（如半导体/光伏等不在 63 目录内的主题指数） |

## 二、数据源

| 用途 | 来源 | 说明 |
|---|---|---|
| 指数估值 | 雪球基金·指数估值（`danjuanfunds.com/djapi/index_eva/`） | `detail` 给 PE/PB/股息率/ROE/日期；`pe_history|pb_history?day=all` 给**周频全历史**（约 2016-10 起、516 点≈10 年）；63 个指数逐个可查 |
| 基金基础信息/费率 | 雪球基金 `fund_individual_basic_info_xq` + `fund_individual_detail_info_xq` | 业绩比较基准、规模、公司、成立日；管理/托管/销售服务费 + 买入首档费率 |
| 基金清单兜底 | 天天基金 F10（`data.fetch_f10(with_manager=False)`） | 雪球接口单只失败时的兜底；**不可作为主源**：并发抓取会 `HTTP 514 Frequency Capped` |
| 近 1/3 年收益 | 天天基金指数基金列表（`ak.fund_info_index_em`） | 只用于基金行辅助展示；缺值显示「—」 |
| 公司非货规模 | `data/fund_company_map.csv` + `data/company_scale_nonmoney.csv` | 同费率下的次序键（展示用，不参与任何评分） |

> **口径纪律**：历史分位由本工具按指数自身近 5 年**周频**序列自算（`(历史值 ≤ 当前值) 占比`），
> 不直接采用第三方分位；页面同时标注估值日期与「分位为程序自算」。

## 三、估值口径

### 3.1 分位与档位（`config.EQ_INDEX`）

- 窗口：近 **5 年**周频；少于此 78 周 → 标「样本不足」；少于 26 周 → 不出档位、不上卡片。
- 分位方向：**分位越低越便宜**（PE/PB 低 = 估值低）。
- 档位阈值（分位上界，改阈值 = 产品决策，需告知用户并记账）：

| 档位 | 分位区间 |
|---|---|
| 极低估 | ≤10% |
| 低估 | 10%–30% |
| 合理偏低 | 30%–50% |
| 合理偏高 | 50%–70% |
| 高估 | >70% |

- 同类横向排名：同 `group`（宽基/行业/策略/海外）内按分位升序，展示「同类 x/n」。
- 展示：主口径分位 + 另一口径分位 + 近 5 年 min/中位/max + 当前值 + 估值日期 + 样本周数。

### 3.2 按指数特点选主口径

| 指数类型/特征 | 主口径 | 理由（页面同步展示） |
|---|---|---|
| 宽基（沪深300/中证500/1000/上证50/180/中证100/创业板/科创50/深证/国证A指/央视50/50AH/海外宽基等） | PE-TTM 分位 | 成分分散、盈利口径稳定，PE 反映市场为盈利付价 |
| 行业-金融/地产/周期（银行、证券、地产、煤炭） | PB 分位 | 盈利周期波动大，PE 易失真；资产端估值更稳 |
| 策略-红利/价值/低波/基本面（含消费红利、标普红利/价值） | PB 分位 | 成分偏金融/公用事业/高分红资产，PB 贴近资产端；股息率现值并列展示 |
| 策略-质量/成长、行业-消费/医药/科技/军工/新能源等 | PE-TTM 分位 | 成长与盈利驱动，PE 是通行锚 |
| 海外（恒生/国企/纳指100/标普500/DAX/MSCI 等） | PE 分位 | 同源可比；QDII 日期滞后在详情注明 |

- **回落**：主口径现值为空或 PE≤0 → 自动改用另一指标，并在详情写「因 PE 缺失/失真，改用 PB 分位」；
  两个口径都不可用（或样本不足）→ 该指数进 `missing`，本期不上卡片。
- **分歧提示**：`|PE分位 − PB分位| ≥ 30pp` → 详情显示一行解释（盈利周期位置/资产端估值分歧），
  不改变档位。

## 四、基金 → 指数映射与准入

### 4.1 准入（`eligible_fund`）

1. 类型 ∈ `["指数型-股票", "指数型-海外股票"]`（`指数型-其他`=黄金/商品，继续排除）；
2. 名称含「增强」→ 排除（主动风险、费率更高）；
3. 名称含 `ETF` 且不含 `ETF联接` → 排除（场内买不到；与债指 v5.17 口径一致）；
4. 其余（ETF 联接 / LOF / 普通场外指数）保留。

### 4.2 基准解析（`parse_benchmark` / `match_benchmark`）

1. 按 `+` 拆成分；剥离 `×95%`/`95%×` 权重、`收益率` 后缀、`(经汇率调整)`/`(使用估值汇率折算)` 括号、
   `人民币计价的` 前缀；剔除现金/存款腿与债券腿（保留非现金成分）。
2. 每个成分在 `CATALOG` 的别名表中做**最长匹配**；同一成分命中多个指数且长度相同 → **歧义拒绝**；
   别名支持排除词（如中证500 排除「低波动/质量/成长」、红利低波排除「100」、创业板排除「50」）。
3. 多成分基准取**最长命中的成分**（如「沪深300价值×70%+综合债×30%」→ 300价值）。
4. 匹配不到的基金记入 `unmatched`（建库日志前 10 条），不进入任何指数组；扩别名见 §九维护。

### 4.3 目录（63）

`fundscorer/eqindex.py` 的 `CATALOG` 冻结 63 条：`code`（雪球代码，如 `SH000300`/`CSI930740`/`HKHSTECH`）、
`name`、`type`（宽基/行业/策略）、`group`（宽基/行业/策略/海外）、`aliases`、`exclude`、`metric`、`why`。
雪球目录新增/删除指数需人工改这一处（本期不做自动发现）。

## 五、基金清单

- 组内按 `(暂停申购, 综合费率↑, 公司非货规模↓, 基金规模↓)` 排序，取前 5。
- **综合费率** = 管理 + 托管 + 销售服务（年化，`fee_total`）；**买入费率**单列（雪球首档，无天天优惠价时如实展示）。
- 每行展示：名称+份额类别、代码、综合费率、买入费率、管理/托管/销售服务、合并规模、近 1 年、申购状态。
- 暂停/封闭/未开放 → 打「暂停申购」红标并排最后；「限大额」仍视为可申购。
- 同一指数下 A/C 份额分别保留（C 类销售服务费高、A 类买入费一次性，用户自选）。

## 七、页面与导出

- 页签：`指数估值`（排在债指之后）；`renderEqIndexList()` 按宽基→行业→策略→海外分段，组内分位升序。
- 卡片：档位徽标、指数名、类型/分组、主口径分位大数字 + 五段分位条、PE/PB/股息率、
  「可选基金 N 只 · 最低综合费率」、同类 x/n；**无基金名称/代码、无勾选对比**。
- 详情（复用 `#detail` 覆盖层，`openEqIndexDetail`）：
  1. 估值总览（档位、主口径、PE/PB 双分位、股息率/ROE、估值日期、样本提示、同类排名、分歧提示、方法说明）；
  2. 估值走势（内联 SVG，月度采样，中位虚线 + 当前点）；
  3. 对应基金（5 行，综合费率/买入费率/管理/托管/销售服务/规模/近1年/申购状态）；
  4. 口径与说明（阈值、来源、风险提示、覆盖限制）。
- 导出：`?export=eq_index&size=xhs|wide`（默认按尺寸行数：xhs 20 / wide 10，`&rows=N` 可覆盖；
  63 行手机图不可读故不默认全量）；`?export=all` 自动多一个页签。导出图**不出现基金名**。

## 八、建库 / 周更 / 缓存

| 步骤 | 命令/触发 | 频率 | 耗时/预算 |
|---|---|---|---|
| 建库（基金→指数、费率、规模） | `python -m fundscorer.eqindex --ingest` | 首次 + 每月（缓存 45 天） | 雪球主源 8 线程实测 **2.9 min**（2,524 只场外非增强、每只 2 请求；单只结果单独缓存，中断重跑秒回） |
| 估值刷新 | 周更管线自动（`eqindex.build`） | 每周五 | 63 个指数 × 3 请求 + 申购状态预取；预算 `budget_s=180`；超时剩余进 `missing` |

| 建库缓存 | `data/eq_index_funds.pkl` + `data/cache/eqfund_v1_{code}.pkl` | 45 天 | 每只基金结果单独缓存，中断重跑秒回 |
| 检查 | `python -m fundscorer.eqindex --check` | 按需 | 打印匹配/指数覆盖/未匹配基准/无基金指数 |

> 6,190 只只能跑 ~1.3 只/s 且大量失败 → 改为雪球基金基础信息/费率为主源，F10 只作单只兜底。

## 九、维护手册

1. **新增指数**：在 `CATALOG` 加一条 `_cat(...)`；`code` 用雪球代码（`SH`/`SZ`/`CSI`/`HK`/`SP`/`NDX`…），
   `aliases` 至少给「指数全称」+「简称」，必要时加 `exclude` 防误配；跑 `--ingest --force` 或等 45 天缓存过期。
2. **新基金配不上**：`--check` 看未匹配基准 → 给对应指数补别名（或确认该指数不在 63 目录、确实不该展示）。
3. **改档位阈值/窗口**：改 `config.EQ_INDEX`（产品决策，需告知用户）；同提交更新本文件 §3 与 `docs/15`。
4. **改目录类型/主口径**：改 `CATALOG` 的 `group/type/metric/why`；
   `metric="pe"`/`"pb"` 之外不新增口径（避免未经验证的第三套分位）。
5. **雪球目录变化**：登录取 63 目录（或对照页面）核对；删除指数时直接从 `CATALOG` 移除并跑 `--check`。

## 十、已知限制与风险

1. **覆盖 63 个指数**：不在雪球估值目录的指数（半导体、光伏、芯片、A500、中证800 等）本期不展示；
   无历史 PE/PB 时不拿价格分位替代。扩围 = 接新数据源（另立项）。
2. **第三方接口**：雪球系接口非官方、无 SLA；已做缓存/重试/旧缓存降级/预算控制；页面署名来源。
   若长期不可用，可退化为「中证官网 20 交易日 PE 快照逐周累积」——但需要时间积累，不能回填 5 年。
3. **分位窗口主观性**：5 年窗口与 10 年/全历史分位可能差异很大（例：中证银行 PB 近 5 年 100% 分位、
   全历史约 61%）；页面只标 5 年口径，不混用。
4. **基准解析误差**：多成分/含汇率折算/名称不含指数名的基金可能漏配或误配；`exclude` + 歧义拒绝 +
   `--check` 未匹配清单是主要护栏。
5. **海外/QDII**：净值与估值日期可能滞后一个交易日，汇率折算带来偏差；详情已提示。
6. **费率口径**：买入费率为雪球首档（无天天基金优惠价），综合费率为三项年化之和；
   不同份额类别不可直接以综合费率比较「一次性买入价」。
7. **合规**：估值分位是历史位置，不是买卖信号；不构成投资建议；页面底部固定免责声明。
