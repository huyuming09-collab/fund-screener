# docs/19 · 指数估值模块（债指之外的指数型基金 · v1.1 基础版）

> **地位**：本文件是「指数估值」页签的唯一口径与维护说明（v5.22 / 模块 v1.1 起）。
> 债指（`indexfund.py` / docs/17）与三池主动评分**不受本模块影响**；本模块只增发 `data.js`
> 的 `eq_index` 键与一个页签，不改 `funds[]` / `pools{}` / 筛选与评分链。
> 用户 2026-10-30 定调：**先区分类型、按一套认可较广的方法做基础版，先把界面做好，后续再加要求。**

## 〇、一句话

**主流指数估值表 + 参考图详情**：一屏列出宽基/行业/海外约 30 个主流指数的估值分位、档位与「定投参考倍数」；
点进详情看 10 年估值图（PE/PB + 指数点位 + 危险/中位/机会线 + ±1σ + 五档色带），以及同指数 **5 只场外低费率基金**。
红利/价值/低波**本期不上线**，债指**单独一个页签、不合并**。

## 一、范围（基础版）

| 项 | 决定 |
|---|---|
| 基金类型 | `指数型-股票` + `指数型-海外股票`；指数型-其他（黄金/商品）排除 |
| 指数范围 | **32 个主流指数**（宽基 11 / 行业 17 / 海外 4）；红利/价值/低波/基本面先不上线 |
| 基金过滤 | 只列**场外**；剔除场内 ETF、指数增强型；ETF 联接/LOF/普通场外保留 |
| 页面 | 两级导航：`稳健型`（中短债/长债/固收+）｜`指数型`（指数估值）｜`债指`（独立） |
| 指数页 | 一张主流指数表（不铺卡片）；行内不出现具体基金名称/代码，只显示「可选基金 N 只 · 最低费率」 |
| 详情页 | 估值结论 + 参考图走势 + 方法口径 + 场外基金 5 只 |
| 排序 | 组内按 10Y 估值分位从低到高（越便宜越靠前） |

## 二、数据源

| 用途 | 来源 | 说明 |
|---|---|---|
| PE(TTM) + 指数点位 | **中证指数官网** `perf/indexCsiDsPe` / `perf/index-perf` | 日频、官方、单请求拿全历史；覆盖中证/上证/科创/北证；按 `publishDate` 截掉回填段 |
| PB / 股息率 / ROE | **雪球基金·指数估值** | 只有 63 个指数有 PB 历史；基础版用于银行/证券/消费/白酒等有 PB 的指数 |
| 基金基准/费率/规模 | 雪球基金基础信息 + 费率明细 | 业绩比较基准用于“基金→指数”匹配；管理/托管/销售服务费 + 买入首档 |
| 基金兜底 | 天天基金 F10 | 雪球单只失败时兜底；并发会 514，禁止作主源 |
| 近 1 年指数收益 | 中证点位（无点位则用对应场外基金净值代理） | 创业板/恒生科技/纳指100/标普500/恒生用基金净值代理，页面标注 |

> 分位由程序自算（`历史值≤当前值` 占比）；不直接采用第三方分位。PB 缺历史时按 PE 单一指标，并在页面标注。

## 三、估值口径（基础版）

- **窗口**：默认 **近 10 年**周频；详情可切近 3 年/近 5 年/上市以来。历史不足 10 年时按可用历史，并显示“上市以来/近3年/近5年”。
- **指标**：PE(TTM) 与 PB 各自算分位；**综合分位 = 可用指标分位的均值**（有 PB 用 PE+PB，没有就 PE）。
- **档位**（估值分位越低越便宜，阈值 20/40/60/80）：

| 档位 | 综合分位 |
|---|---|
| 极低估 | ≤20% |
| 低估 | 20%–40% |
| 合理偏低 | 40%–60% |
| 合理偏高 | 60%–80% |
| 高估 | >80% |

- **定投参考倍数**（基础版仅作历史分位参考，不是已验证策略）：极低估 4x / 低估 2x / 合理偏低 1x / 合理偏高 0.5x / 高估 0（暂停）。
- **类型差异**：宽基用 PE/PB 综合；行业同样用综合（PB 对盈利波动更稳）；海外用 PE/PB；红利/价值逻辑不同，本期不纳入。
- **参考图**：左侧统计卡（当前值、综合分位、指标分位、危险值/中位/机会值、最大/最小、均值/标准差、z 分数、指数点位、样本周数）；主图五档色带 + 估值线 + 指数点位（右轴虚线）+ 危险/中位/机会 + 均值±1σ；顶部切 3/5/10/年/全 + PE/PB。
- **明确边界**：基础版**没有**把回测/验证做进页面，也没有结构闸/置信度；“定投参考倍数”只是分位映射，不能当作收益承诺。用户已确认先做界面，后续再加验证与基本面。

## 四、指数 → 基金映射

- 基金基准解析 + 别名最长匹配（`parse_benchmark` / `match_benchmark`）；多成分取最长命中；歧义拒绝；未匹配记入 `unmatched`。

## 六、页面/交互

- **导航**：第一行分组（稳健型 / 指数型 / 债指），第二行该组页签；`switchTab()` 保持兼容。
- **指数表**：分组头（宽基/行业/海外）+ 行；行内：档位徽标、指数名、分组/基金数/最低费率、10Y 分位、定投参考倍数、PE/PB/近1年/方法。顶部「全部/宽基/行业/海外」筛选。
- **详情**：估值结论（档位、倍数、综合分位、指标分位、危险/中位/机会、最大/最小、均值/标准差、z、点位）、估值走势（3/5/10/全 × PE/PB）、方法口径、场外基金 5 只、免责。
- **导出**：`?export=eq_index&size=xhs|wide` 仍可用（按尺寸取前 20/10 行）；`?export=all` 含新页签。
- **回退**：旧 data.js 无 `eq_index` 时页签不出现；模块失败只让页签消失，不影响三池/债指。

## 七、维护

```
python -m fundscorer.eqindex --ingest    # 基金→指数建库（首次/每月；缓存 45 天）
python -m fundscorer.eqindex --build     # 只抓估值并组装（调试）
python -m fundscorer.eqindex --check     # 看主流指数基金覆盖/未匹配
python -m fundscorer.pipeline --skip-refresh   # 生成 data.js（周更/验证）
```

- `EQ_INDEX["enabled"]` 总开关；`tiers` 阈值 20/40/60/80；`fund_list_n=5`；`peak` 见 `config.py`。
- 新增主流指数：在 `CATALOG` 加一行（`code/name/type/group/aliases/cs/default_metric`），加入 `_MAINSTREAM`，重跑 `--ingest`。
- 红利/价值/低波：`_DEFER` 里的条目暂不上线；后续单列版块。
- 指数点位缺失（深交所/海外）：`_CLOSE_PROXY` 用场外基金净值代理，页面标注。

## 八、已知限制（基础版）

1. **没有回测/验证**：分位→倍数是经验映射；后续加“已完成周期/未平仓/策略 vs 固定定投”证据后再决定是否启用严格倍数。
2. **PB 历史只有 63 个**：A500/科创/半导体/光伏/新能源车/人工智能/机器人等只有 PE；页面标注“PE·分位”。
3. **历史长度**：A500 上市以来约 2 年、科创100/200 约 3 年、创业板/海外用雪球 2016 起；分位样本不足 10 年的标注“可用 X 年”。
4. **红利/价值逻辑不同**：本期不纳入，避免把股息率/价值策略混进 PE/PB 表。
5. **无结构闸/基本面**：行业上限下降、盈利下修等尚未进入指标（后续加 EPS/ROE 趋势与置信度）。
6. **数据口径**：中证 PE 为 TTM、雪球 PB 为第三方口径；跨源可能差 1–2 个 PE，边界处不翻转结论。
7. **基金清单**：只列场外、只按费率/规模/状态排序；跟踪误差尚未计算。
