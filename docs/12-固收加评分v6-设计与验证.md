## 一、需求与约束（2026-10-19 用户原话要点）

1. 参考所给指标表设计固收+评分（**不参考其中分数**），另加**超额收益与超额胜率**；
2. 经理一栏要考虑**多王牌经理共管**一只基金的情况；
3. 目标：**高收益高波动**与**中高收益低波动**两类都要能上榜、排名靠前；
4. 指标不设限：不必须用表中全部指标（夏普与索提诺重复可合并），表中没有的（如近一年回撤）也可用；
5. 方法要求：**设计 → 探索 → 验证 → 回检**，最终回头看是否符合实际逻辑。

## 六、验证二：双目标达成度 + 剂量-反应（★跑后探索，非预注册）

双目标度量：候选池内按（收益中位，波动中位）切四象限，**H = 高收益高波动**、**L = 中高收益低波**；
表示度 = TOP 内占比 ÷ 池内占比（1.0 = 未被排斥）；名次分位 = 组内成员在池中的名次百分位（100 = 最好）。

| 方案 | H 表示度（训/验） | L 表示度（验） | H 名次分位（验） |
|---|---|---|---|
| S0 | 0.71 / 0.80 | 3.58 | 58.0 |
| S2 | 0.68 / 0.83 | 3.13 | 53.2 |
| S3（+12 分收益超额） | 0.92 / **1.07** | 3.23 | 60.3 |

**结构性事实**：比率因子天然偏爱低波（分母小），L 组表示度全部 ≥3.1、H 组全部 <1.05。
把收益/超额加到 6~9 分可把 H 表示度推到 0.90~1.06，但代价是验证段前瞻卡玛
1.5259 → 1.3788~1.4801（−3%~−10%），且训练段全线劣化（−5%~−9%）。
**剂量曲线不单调（噪声大），不存在"无损提高 H 可见度"的剂量点。**

**S4 是全部实验里唯一两段都不劣于 S0 的改动**——消掉 0.902 冗余不改变行为，验证段还略好。

  属**个体不可识别**而非"类型被排斥"（该基金长项因子验证段为负，见 §3）

**解读**：你的双目标不是"没达成"，而是**已经以正确的方式达成**——
