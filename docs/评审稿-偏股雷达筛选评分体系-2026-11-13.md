## 3. 评分系统（W3，6因子加权 0-100）

### 3.1 因子（先各自转**合格池内分位**0-100，再加权）

| 因子 | 定义 | 依据 |
|---|---|---|
| **F1 持续性 27%** | 5年**同格逐年排位的均值** | 检验9 最强单信号（IC +0.05~0.17 三起点全正）；格内比较=风格周期免疫 |
| **F3 风格调整超额 25%** | 5年收益 − **自身风格指数**5年收益（均衡/无代理桶用类型合成） | 剥风格beta：逆风风格里跑赢自己风格指数者拿高分 |
| **F5 防运气 19%** | 去掉最佳年后的风格调整超额 | 连续版"去运气"；IC 全正 |
| **F2 胜率 15%** | 5年中跑赢同格中位的年数 | 持续性直译，与F1互补 |
| **F6 质地 14%** | (任期分位+从业分位)/2 | 定性精简；小权重防"熬年头刷分" |
| ~~F4 稳定性~~ **0%** | −(风格调整超额逐年标准差) | **三起点IC全负（-0.06/-0.13/-0.02）数据证伪**：低波动基金未来同行排位反而略差（beta U型审计一致：最高五分位28% vs 中间14% vs 最低25%）→ 权重归零，只存CSV供回核 |

### 3.2 权重推导（数据定权，非拍脑袋）

- **LOOCV-IC**：用2个年度起点的因子-未来IC定权重、第3个起点验证（防过拟合）；
  生产用三起点平均IC归一 → **W3 = F1 27 / F3 25 / F5 19 / F2 15 / F6 14（F4=0）**；
- 对照组：W1 等权、W2 持续性核心导向（F1 30/F3 20/F4 15/F5 15/F2 10/F6 10）；
- **三起点IC全胜**：W3 +0.053/+0.073/+0.180 vs 等权 +0.032/+0.036/+0.162，且LOOCV自动把反向F4归零。

### 3.3 经理级聚合与缺因子处理

- **经理分 = 名下过考基金的 W3 最高分**（min-rank 口径，检验19 同源）；保护期回落至入围基金最高分；
- 缺因子：`(Σ w·pct) / Σw` **固定分母**（缺项按0贡献）——与验证脚本逐行同款；
  后果=数据不全者被保守压低（合格池内可算分者基本因子齐全，影响面小，但评审可质疑公平性）；
- **短窗（近1年）业绩不进评分；风险（回撤/波动）只展示不做因子**（F4反向+拍板）。

### 3.4 三检验裁决（scripts/eq_score_test.py）

| 检验 | 方法 | 结果 | 诚实披露 |
|---|---|---|---|
| **18 预测力** | 榜内前20 → 未来同格排位，三起点 | W3 最优或并列 | **榜内随机基线已高（60-75%未来优秀——闸已把人选完）**；评分边际精度受 **48%市场噪声天花板**限制；2025单年前瞻（噪声最大）W3略低于随机。**评分价值=排序稳定+公平，不是魔法精度** |
| **19 前列稳定性**（用户核心诉求） | W3/等权/年限序/计数序 的周/月 top 留存 | W3 周 top10/20 留存 **70-90%/80-85%**、月 **80%/80-90%**；接近最稳的年限序（90%/80-85%），远优于计数序（周50-60%、月top10仅40%）；叠加双周确认 → **在榜成员留存100%** | 留存高≠预测准，是稳定性证明 |
| **20 同类公平**（不冤枉逆风者） | 2025逆风cell高分者 vs 顺风cell低分者的未来排位 | 分数vs原始收益相关仅 **~0.6**（不被收益主导）；逆风高分者未来排位 **69.2% / 优秀率70%** 优于顺风 28.3%/10% | **子样本 n=10，看趋势不看定论** |

## 4. 名单动力学（两榜考卷制 + 双十直通 + 绝对门槛）

### 4.1 结构（三层）

```
L1 资格 = S1池 ∧ S3任本基金≥5年 ∧ S4净值≥5年 ∧ 从业>6年        （身份与数据，无业绩条件）
L2 分榜考卷：
   老将榜（从业>10年）= G3s 中档：5年中 ≥3年 进同格前25%
   新锐榜（从业6~10年）= G4s 严档：5年同格平均排位 ≥70
   ★双十直通（2026-11-13）：双十 = 从业>10年 且 从业年化>10% → 免考卷免门槛，全部上榜
   ★绝对门槛（2026-11-13）：非双十的过考基金须 5年年化 ≥0（先滤基金再取最高分作计分基金）
L3 复评 = 周滚动 + 出榜双周确认：
   首过不出；连续两次不过才出；离职/从业出闸/资格失效（含断档、数据完整下无入围基金）即时出
   毕业（从业满10年）即考老将卷：过→迁移（榜龄保留），不过→落榜
   数据不全 → 冻结不判（不冤枉）
状态文件：本地 JSON（入场期/连续不过次数/毕业标记；gitignore 运行态，丢失=榜龄重计）
```

### 4.2 考卷阈值的依据

- **老将"稍稍放宽"**（检验13，同卷对照）：老将 G3s 精确率 **49.5%** vs 新锐用同卷41.4%；
  G4s 老将54.5% vs 新锐42.6%——老将池更可预测，中档卷即可达新锐严档的精度；
- **毕业即考**（检验16）：满10年者过老将卷实测 **87%**；
- **双周确认**（检验17）：纯周滚动下考卷边界噪声大（老将榜周留存77.3%、新锐82.9%）——
  压线者单周进出是**测量噪声不是能力变化**；双周确认把在榜留存提到100%，同时保留
  "连续两周不过=真掉队就换"；
- **曾经的 P 闸被否决**（演化链，检验8）：R6三闸（逐年≥3年正超额+去最佳年仍正+5年绝对超额>0）
  伪前瞻最优（中位-5.52% vs 对照-7.26%），但**年度复评留存仅42.7%（112/262）=年换血57%**
  → 只配做入场券，不做复评；最终方案=考卷（稳定性导向）+双周确认。
  R6三闸的"防运气"思想下沉为评分因子 F5；R6做入场闸的精确率39.4%≈现闸（检验9），未采纳。

### 4.3 双十直通与绝对门槛的组合逻辑（评审重点）

- **双十 = 从业>10年 且 从业年化>10%**（用户澄清"不是本基金任期"）：
  "从业年化"取**任职最久现任基金**的几何年化（与各平台该基金"任职年化"同公式同起始日）。
  当期：从业>10年407人 → 双十89人 → 在榜76人（13人因L1资格/数据不全未入——
  没有5年基金就没有可展示的5年指标，"全部上榜"在此让位于数据事实）；
- **设计意图**：从业10年+年化10%是**最强的"持续优秀"证据**（穿越周期的复利记录），

- **绝对门槛**（用户在选项中选"1"）：非双十的过考基金须5年年化≥0——

- **张力（如实披露）**：双十免门槛 → 20名计分基金5年年化为负的经理在榜
