> **V5.2 速览（2026-10-15）**：应"收益更高+曲线平稳"目标做第二轮回测（`docs/06`），
> **仅固收+池**换用 calmar 目标 IC 权重（动量 24.2→2.75、风险因子 19→77.3），
> 验证段收益−2×回撤 +57%、回撤 −27%；短债与中长期纯债池维持 V5.1（差异为噪声）。

> 定位：**筛选能够长期投资的债券型基金**。
> 主窗口 = **近 5 年**（覆盖 2020 利率上行、2022-11 赎回潮、2024-09 股债切换多轮压力期），

> 核心排序指标为**长期性价比指数（LVI）**——用更小的风险换取更高的收益，且该指数自身排名必须稳定。

## 一、分类与分池（规则 R0）

只分 **纯债型** 和 **固收+型**；纯债型内再分两个比较池。

```
合同不投股票 且 不投可转债/可交换债 且 近4季平均股票仓位 ≤2%  →  纯债型
否则（含权益增强：股票/可转债/打新/港股，或基准含股指）        →  固收+
纯债分池：近4季平均久期 ≤1 年 = 短债池；>1 年 = 中长期纯债池
```

## 五、关键指标口径手册

### 5.1 回撤修复速度

```
① 显著回撤 := 深度 ≥ max(同池近5年回撤中位数 × 50%, 绝对下限)
   绝对下限：短债池 0.15% / 中长期纯债池 0.5% / 固收+ 池 3%
② 取近5年最深一次显著回撤：D=深度，T=谷底→重新创新高交易日数（未修复计至数据截止日）
③ 得分（占子项满分比例）：
   纯债： T≤15 →100%；16~30 →85%；31~60 →70%；61~120 →40%；>120 →0
   固收+：T≤30 →100%；31~60 →85%；61~120 →70%；121~240 →50%；>240 →0（+红线 R7-5）
④ 近5年【无显著回撤】：得分 = 满分 × min(1, 成立年限 ÷ 3)   ← 杜绝新基金虚高
```

### 5.2 经理资质调节规则 R3（固收+ 回撤容忍度）

```
"长期业绩良好" := 现任经理任职期内每个自然年同类排名 ≤50% 且 各年平均 ≤33.3%（两条件同时满足）
                  观察年份 = 近5自然年 ∩ 任职期，可得年份 ≥3 年才有资格
满足 → 预警线 13%、上限 15%；不满足或可得<3年 → 预警线 8%、上限 10%
```

### 5.3 风险代价（LVI 的分母）

```
风险代价 RC := 0.6 × 近5年最大回撤 + 0.4 × 近5年下行波动率（仅负收益日的年化标准差）
权重理由：回撤是持有人最直接的痛感（V2 输入"回撤小"），下行波动剔除"向上的波动"不算风险
```

### 5.4 长期性价比指数 LVI（V5 核心新增）

**定义**：单位风险代价所换取的超额收益，直接量化"长期来看用更小的风险换取更高的收益"。

```
超额收益 EX := 基金近5年年化收益 − 业绩基准近5年年化收益
LVI_5年 := EX / RC
LVI_3年 := 超额收益(3年) / RC(3年)          （交叉验证窗口，防单一窗口偶然性）

打分：
  LVI_5年得分 = 12(纯债)/11(固收+) × 同池百分位(缩尾后)
  LVI_3年得分 = 6 × 同池百分位(缩尾后)
边界处理：
  RC ≈ 0（几乎零回撤）→ LVI 取同池最高值+1（防止除零虚高）
  EX < 0（跑输基准）→ 百分位自然趋近 0，不额外惩罚
  超额回撤比、卡玛、夏普【仍计算并展示】，但不再进入总分（消除共线性重复计分）
```

**为什么 LVI 而不是卡玛/夏普**：卡玛只看回撤、夏普只看波动、超额回撤比只看超额对回撤，
三者两两相关 >0.8（V4 自查发现的重复计分隐患）；LVI 把"超额"与"综合风险代价"合成**一个**指数，
既保留"200%超额可接受150%风险"的动态平衡观（V2 输入#6），又让总分对同一风险只计一次。

### 5.5 经理全产品历史年化（V5 新增，回答"参考经理而非本基金"）

```
产品集合 := 现任基金经理【职业生涯管理过的全部公募基金】（含已离任产品）
            剔除：任职 <2 年的产品（年化无意义）、货币基金（与目标池无可比性）
单产品年化 := (1 + 任职总回报)^(365 / 任职天数) − 1     ← 数据源：天天基金基金经理页
经理指标   := 单产品年化的【中位数】（不用均值：防"一款爆款"拉高整体）
打分       := 同池内各基金现任经理该指标的百分位 → ×4 分
             产品集合为空或全部任职<2年 → 0分并标注 insufficient_manager_history
数据可得性已验证：天天基金 /manager/<id>.html 提供每只产品的任职天数与任职回报
```

### 5.6 费率（份额可比口径）

```
持有成本 := 管理费率 + 托管费率 + 销售服务费率（该份额类别实际计提）
比较范围 := 同池 且 同份额类别（A比A、C比C）；样本<10 只放宽全池并标注 fee_peer_relaxed
申购费/赎回费【不计分】仅展示：申购费渠道折扣差异大，赎回费随持有期递减（长期持有趋于0）
```

### 5.7 经理全产品年化与从业年限（V5-r2 提权至 20 分）

```
经理分 := 4×本基金任职分 + 5×从业年限分 + 11×全产品年化分位分   （满分20）
本基金任职 := ≥5年=100 / ≥3年=70 / ≥1年=30 / <1年=0（并触发红线R7-1）
从业年限   := ≥8年=100 / ≥5年=70 / ≥3年=40 / <3年=0（数据源：天天基金经理全表）
全产品年化 := §5.5 口径 → 同池百分位
```

用户口径："基金终究要看基金经理的能力"——权重从 8 分提到 20 分，收益确定后经理是第一区分项。
已知局限：金牛奖/英华奖等荣誉**无免费数据源**（F10 与 akshare 均无字段），暂以
"从业年限 + 全产品年化"代理；如需真实荣誉数据需手工维护获奖名单。

### 5.8 风险"门槛给满分"（V5-r2 新增，替代纯百分位）

**问题**：纯百分位下，长城短债 0.57% 波动（绝对意义很稳）因"有人更低"被打到 19 分，
把 97.5 的收益分全吃掉——风险项过度区分，违背"纯债够稳即可"的定位。

```
门槛值 := 池均值 × 1.5    （≤ 此值 → 100 分，不再区分）
归零值 := 池均值 × 4.0    （≥ 此值 → 0 分）
之间   := 线性插值
适用   := 纯债池 mdd_5y/mdd_3y/mdd_1y/vol_5y + 固收+池 vol_5y
         （池样本 ≥20 才启用门槛，否则退回百分位）
注意   := 回撤修复、月胜率仍用百分位/分档；固收+回撤仍用 §5.2 分档+经理资质调节
```

## 六、排名稳定性保障（V5 新增：指数自身不能剧烈翻转）

**问题**：单期评分排前 1%，一年后跌到后 1% —— 根因有四：
① 窗口太短，单个事件（踩雷/经理变更）权重过大；② 百分位是相对量，同池整体变化会"推挤"个体排名；
③ 极端值扭曲分布；④ 星级在阈值附近抖动。对应五层机制：

| 层 | 机制 | 防什么 |
|---|---|---|
| L1 慢窗口 | 所有主指标基于 5 年滚动窗口，单日/单月事件在窗口内占比 ≤0.4% | 单事件撬动排名 |
| L2 缩尾+分位 | 5%/95% winsorize 后再算同池百分位 | 极端值扭曲分布 |
| L3 **滑动中位平滑** | **对外展示/排序用的 LVI 与总分 = 近 6 期评分的中位数**（当期值实时算、仅作内部状态） | 单期异常被中位数吸收；某一期数据错误不会立即反映到排名 |
| L4 **星级滞回** | **升档按当期分；降档需连续 2 期低于阈值**（如五星 85 分：一期 84 不降星，连续两期 84 才降） | 阈值附近抖动、"这月五星下月三星" |
| L5 **事件观察期** | 触发红线事件（经理变更/单日异常）→ 标注"观察期"并**冻结降档**，观察 1~2 期后按新状态重估 | 把"突发事件的临时冲击"与"质地恶化"区分开 |

**配套展示原则（展示页面）**：只展示**档位**（前10%/前25%/中位…）与星级，不展示"第 X%"精确名次——
百分位本身是零和的，精确名次天然不稳定，档位展示既诚实又稳定。

**稳定性验收门槛（上线前回测，见 §7）**：
- 连续两期总分排名的 Spearman 秩相关 ≥ 0.9；
- 上期前 20% 的基金，下一期仍处前 30% 的比例 ≥ 80%（"排名跳变率"≤20%）；
- 不达标 → 提高 L3 平滑期数（6→12）或延长窗口，而非直接上线。

## 七、红线、更新机制与回测

### 红线 R7（命中 → 总分封顶 60 分；与 V3 修订一致）

1. 现任经理·本基金任职 < 6 个月；
2. 最新规模 < 5000 万且连续两季下降；
3. 回撤双条件：近1年回撤 > 绝对阈值（短债0.3%/中长债1.5%/固收+调节上限）**且** 超出同池中位幅度 > 阈值一半；
   系统性回撤期（同池中位 ≥ 阈值一半）仅看超额回撤 > 阈值一半；
4. |单日跌幅| > max(3×同池中位日波动, 绝对下限：短债0.10%/中长债0.30%/固收+1.5%) 且之后 20 个交易日未修复一半；
5. 固收+：近5年最深回撤 > 240 交易日未修复。

修正 R8（±5 封顶）：成立 ≥5 年且历任经理更替期间业绩连续为正 +2；机构/费率/规模已计分不重复扣。
星级 R9：五星 ≥85 且 ≤10%；四星 ≥75 且 ≤25%；三星 ≥60；二星 ≥45；其余一星。
**升降档叠加 §6-L4 滞回规则。** 1~3 年基金有分无星。

### 更新机制

| 触发 | 动作 |
|---|---|
| **每月 8 日** | 全量重算 5/3/1 年窗口 + 重排百分位 + 滑动中位平滑 + 滞回判定星级 |
| 季报/半年报 | 更新质地数据（规模、机构比例、经理、费率、经理全产品年化） |
| 事件驱动 | ① 经理变更 ② 单日异常跌幅 ③ 规模破 5000 万 ④ 新基金满1年入池/满3年解锁星级 ⑤ 回撤破预警线 → 标注观察期，冻结降档 |
| 方法论升级 | 全量重算；**历史评分快照永不覆盖**（评分走势展示 + 回测数据） |

### 回测验证（上线前置，双门槛）

1. **有效性**：月末评分快照分组，高星基金未来 6/12 个月收益更高、回撤更小
   （Spearman 秩相关 > 0.3，p<0.05）；
2. **稳定性**：§6 末尾的两条稳定性门槛；
   不达标 → 调整权重/平滑参数 → 重测，通过才上线。

## 附录A：设计输入记录

**第一批（持有人实战经验）**：只分纯债/固收+再同类比较；纯债稳定性第一（回撤小、修复快、胜率高），
其次收益；固收+可担小风险换收益，回撤10%偏高但看情况（经理牛、长期10%、偶尔15%可接受），
长期稳定向上、不能半年一年未修复；必要因素：成立年限、经理从业年限（完整周期验证）、
稳定创造超额（非昙花一现）、费率；辅助参考：晨星评级、公司规模、机构比例（均计分）；
