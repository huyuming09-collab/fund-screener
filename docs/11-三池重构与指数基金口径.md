## 二、混合一级的行为分层（v5.4 新增）

`债券型-混合一级`（可转债增强）是**唯一需要看净值才能分池**的类型：

```
近5年波动 < 固收+ 的 vol_5y_min（2.5%） → 长债池（行为即长债）
≥ 2.5%                              → 固收+ 池（真转债增强型）
净值不足半年（判不了）            → 固收+ 池（沿用 v1.1 既有口径，不误塞长债）
```

阈值与 `SCREENS["fixed_plus"].vol_5y_min` **同源**（不硬编码两套）。
实测全集 780 只混合一级中，绝大多数波动落在长债档，与"相似属性同池"一致。
**理由**：这些基金的波动/回撤/胜率与长债完全同档（用户决定"不需要加波动上限"——
信任现有筛选条件与评分能给高波动基金打低分）。

## 三、债券指数基金独立口径

### 3.1 分池（中短债 vs 长债）

依据抽样实测（151 只有效债券指数）：

| 标的久期 | 样本 | 波动 p10/p50/p90 | 近5年回撤 | 5年年化 |
|---|---|---|---|---|
| 短端（1-3年/短融/同业存单） | 80 | 0.21 / **0.65** / 0.79% | 0.79% | 2.74% |
| 长端（1-5/3-5/7-10年、总财富） | 68 | 0.89 / **1.21** / 2.10% | 1.62% | 3.66% |
| 异常（可转债/超长债） | 3 | **7.69%** | 14.50% | — |

两端重叠仅 0.8~0.9% 一段 → 按标的久期即可分离。三步判定
（`scorer.index_pool()` / `classify()`，**新基金按当时基准+净值现算，不缓存归池结果**）：

1. **跟踪基准**优先（含 `0-2年/1-3年/7-10年` 等区间 → 上限 ≤3 年短、≥5 年长），
   名称兜底；
2. 文本判不出（亚债中国、信用债综合、恒定久期、区域综合等）→ **近5年实测波动终判**
   （<0.7% 短债、0.7~2.5% 长债）；
3. 含 `可转债/可交换/转债` **无条件排除**；实测波动 ≥2.5% 或净值不足 → `EXCLUDED_POOL`
   （标记为 `excluded`，指标照常采集但不进任何池，避免每周重算被计为失败报警）。

实测 125 只"文本判不出"的债券指数：81 只 <0.7% 归短债、37 只归长债、**7 只 ≥2.5% 不入池**。

### 3.2 筛选闸差异（`screen_candidates(index_fund=True)`）

| 闸 | 主动基金 | 指数基金 |
|---|---|---|
| S1 规模≥5亿 | ✓ | ✓ |
| S2 经理从业≥5年 / S3 任本基金≥3年 | ✓ | **不适用**（不看经理业绩） |
| S4 成立年限 | ≥**5** 年 | ≥**3** 年（`config.INDEX.min_nav_years`，指数多为 2023 年后成立） |
| S5 无单日异常涨幅 | ✓ | ✓ |
| P1 综合分位≥45% / P2 年度分位中位≥55% | ✓ | ✓（在**指数子集内**计算） |
| S6/S7/S8 | 仅固收+ | 不适用 |

### 3.3 排名与打分（穿插插值）

> **v5.11 起现行口径为 v2**（3 年族同族相对筛选、`score_index_pool` 指数评估卡、H1′ 条件锚点 A/B/C），
> 见 `docs/17 §4`；本节自 v2 实装起为 **v1 设计存档**（下方双锚线性与"锚分数极值"规则仍是 H1′ 分支 A/C 的祖先口径）。

`fundscorer/indexfund.py`：

1. **业绩口径 = 近三年**（`config.INDEX.return_metric="ret_3y"`，
   `ann_return` 在历史不足窗口时用全期年化，即项目既有 R2 口径）；
   主动榜一侧用**同一列**建区间（两侧必须同口径）。
2. 指数基金业绩落在主动榜第 k 与 k+1 名之间 → 分数 = 该两只分数按业绩**线性插值**
   （"业绩在谁和谁之间、打分就在这两个分数之间"）。
3. **业绩高于全部 / 低于全部** → 锚定**榜内最高分+ε / 最低分−ε**（列首 / 榜末之后）。
   > 早期实现锚"业绩极端那只的分数"是错的：主动榜按**分数**排序、业绩与分数非单调，
   > 导致业绩全场最高的指数基金被排到第 4 名。已改为锚分数极值（回归测试锁死）。
4. 业绩与某只主动基金**完全相同** → 主动优先（分数 −ε，指数排其后一位），
   否则同分会被 code 字母序裁决、指数可能反超主动。
5. **同一跟踪指数最多 2 只**（`config.INDEX.per_index_max`）：
   跟踪指数标识从业绩基准截取（去掉 `+银行利率` 现金拖累腿、`×95%` 权重、
   `收益率/全价` 后缀）；组内按 **费率升序、公司非货规模降序** 取前二。
   实测长债池"同指数去重挤出 3 只"。
6. 合并后按分数降序（平局按 code）截断 `top_n` 重排名次。

**锚点随卡片下发**（`f.score_basis` = `{metric, ret, score, lo, hi}`，
lo/hi 含 `{rank, name, ret, score}`）：详情页"评分依据"逐条展示
"本基金业绩 / 下邻锚点 / 上邻锚点 / 插值得分"，让用户可核对上述规则。
主动基金 `score_basis = null`，仍显示"评分明细·分项贡献分"。

> 为什么必须展示锚点：指数基金的显示分是**插值分**，与主动评分卡的分项之和必然不等
> （实测最大差 **24.7 分**）。若照常显示"分项贡献分"，详情页会自相矛盾。
> 同理，指数基金的"基金经理"区块替换为"指数评估口径"（费率 / 公司非货规模 / 合并规模）。

## 四、新成立基金的归池机制（用户第四条要求）

不依赖任何"每只基金一次归池"的缓存：

1. **全集每周重建**：`batch.build_universe()` 在周更 `refresh()` 内执行
   （列表缓存 3 天），新发行的基金自然进入全集；封闭定开与 `EXCLUDED_TYPES`
   每次按当前类型名判定。
2. **指标层归池每期重算**：`scorer.collect_metrics()` → `classify(f10, nav_df)`
   用**当时**的 `type_text` + `benchmark` + 净值现算，不读取历史归池结果。
3. **指数久期判定不落盘**：`index_pool()` 每次由名称/基准推导；
   文本判不出的走净值实测；净值不足半年的标 `excluded`，**等数据够了下期自动入池**。
4. `classify()` 的返回值 `EXCLUDED_POOL`（`excluded`）区别于抛异常：
   指标照常采集，但不进入任何池的 `load_screen_inputs` 过滤，周更不会反复报警。

## 六、**需要用户确认的边界取舍**

1. **业绩高于全部主动基金的指数基金 → 排列首**。
   规则自然延伸的结果（业绩没有"落在谁和谁之间"时只能放在最前）。
   本期后果：中短债第 1、长债第 1~2 名由指数基金占据，原主动冠军降到 2/3 名。
   若不希望指数基金夺榜，需改为"指数基金名次不超过主动第 N 名"或"分数锚定但不越位"。
2. **7 只波动 ≥2.5% 的债券指数不入池**：`511090 鹏扬30年国债ETF`（成立 2023-05、
   301 亿、波动 6.27%）、`511130 博时30年国债ETF`（2024-03，另被 S4 的 3 年闸挡下）、
   `511180/511380 可转债ETF`（7.69%/9.59%，文本即排除）、
   `019566/021417/023062 绿色债指数`（2.58~5.12%，其中两只成立<3 年）。
   其中**鹏扬30年国债**是唯一规模大、年限够的真判例：按"波动超纯债行为带"排除。
   长债池无 S6/S7 上限（用户决定不加波动上限），而指数按**纯业绩**排名、
   **无风险惩罚**——因此超长债指数必须在分池层排除，否则会以业绩直冲榜首。
   → 请确认这个权衡：**要"不设波动上限"还是"30年国债ETF 可入长债榜"**。
3. **跨池 calmar 不可比**（评审稿建议②的口径问题）：仍沿用既有评分，
   三池分数只在池内排序、不跨池比较。
4. **`_deltaTxt`/环比**：本期三池均无历史，"新增"标记未触发；
   下期（2026-10-23）开始恢复环比。
