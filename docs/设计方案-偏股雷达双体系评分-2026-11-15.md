# 设计提案 · 偏股雷达双体系评分（新锐/老将分设）v1.0 · 2026-11-15

> 目标场景（用户）：主动型仓位10%-20%（**10%底仓常驻**，战术部分行情火热转债券避险），
> 从偏股雷达**择优选人**——新锐1只、老将数只；后续接入资产配置模块
> （**债券 / 红利 / 指数 / 主动 四部分，红利与指数是两个独立部分**；火热转防守、低估加进攻）。
> 本模块职责=每周稳定给出**可直接取前几名**的评分体系，供用户与读者参考。
> 地位：**设计提案，等用户拍板后才进入实施**（评分权重/阈值=产品决策，AG §7）。

## 0. 用户拍板记录（2026-11-15 四问四答）

1. **展示**：类债基榜——每榜前20（或某分数线以上）展示；主看前几名，但**全因子数据必须可核实**
   （"为什么前几名高、差距在哪"要看得见）；**不能为稳定而稳定——禁止迟滞机制**：
   优秀的经理就应该持续优秀，一会进一会出=踩风口/运气；前几名大变化必须**及时发现**。
2. **持有层换人**：评分每期（每周）诚实更新，**已持有的只在"大的变动/基金经理换人/严重问题"
   才换**——不频繁交易；名次小幅后移可容忍，前几名稳定在靠前区域即可。
3. **体系分开程度**：**允许异因子**（新锐/老将完全分开设计）；过拟合靠后续持续跟踪纠正。
4. **节奏**：每周更新。（配置层：红利与指数是两个部分。）

### 1.3 持续上榜率的两口径矛盾（如实记录）

连续口径（本表 P_up ρ=-0.09 老将/0 新锐）：不支持。可能因中间段（50%≤P<80%）拖累
与通道混合。**结论：P 不入评分，只作展示与警报**（待后续跟踪再议）。

## 2. 两套体系设计（初版，权重待 walk-forward 定稿）

### 2.1 老将体系（从业>10）
- **因子池（证据筛后）**：mom1 近1年动量、F3 风格调整超额、F1 持续性、mdd 5年回撤（反向）
  ——候选权重按"多期 IC 归一"（检验18同法）+ walk-forward 校验
- **剔除**：F6 资历（显著为负）、F5（无区分）、P_up（口径矛盾）
- **考卷**：保留 G3s（严格版+3.3pp）
- **双十**：见待拍板①（证据不支持免考卷特权）
- 三硬闸 G1/G2/G3 保留（基金级）
### 2.2 新锐体系（从业6-10）
- **因子池**：F3、mom1、F1（≤3个，样本独立度低、防过拟合）
- **剔除**：F6（窗口窄）、F5弱（可留可去，walk-forward定）
- **考卷**：保留 G4s（严格版+2.4pp；修正探针3）
- **回撤/波动**：样本内为正（高波高收益）——作**闸**还是**因子**见待拍板③
- 三硬闸保留
### 2.3 权重方法与防过拟合（用户已接受过拟合+跟踪纠正）
- 定稿：多期 IC 归一 → walk-forward（用"截至该期"数据定权、下一期验证）→ 过全期检验才上线
- **跟踪机制（每周）**：输出各因子滚动 IC 方向表；任一因子连续3期方向翻转 → 触发复议
  （这就是"过拟合持续纠正"的落地）

## 3. 展示设计（债基榜同款 + 因子拆解）

- **榜单**：每榜前20（或分数≥下限，双条件取并集，分数线待定稿）；列=名次/经理/总分/
  各因子分位（持续/超额/动量/回撤）/双十标/持续上榜率P/规模旗
- **因子拆解（核心新件）**：详情页=各因子"分位×权重=贡献"条形图；
  **差距归因**："你比第1名低在哪"——逐因子差值排序（回答"为什么前几名高"）
- **每周更新**：周日管线后评分与排名即刷新；名单成员资格仍双周确认（既有状态机不动）
- 导出 xhs/wide 榜单图加因子列；data.js mgr 段加 `factor_breakdown` 字段

## 4. 稳定性与及时发现（无迟滞的实现方式）

- **不加任何迟滞/缓冲**（用户明令）——稳定性只能来自标准本身合理
- 验收指标（只测不干预）：相邻月 top3 重合率、top5 月换手、季度 top10 换手；
  用8期回测先测**现标准与新标准各自能到什么水平**，再定验收线（建议目标：相邻月 top3 ≥2/3）
- **前N异动警报（每周随榜输出）**：①掉出前N超过10名 ②分数骤降（>15%）③基金经理变更
  ④触发硬闸 ⑤双十失效 ⑥考卷翻车 → 分"严重/关注"两级——这是"及时发现"的载体，
  也是你持有层"严重问题才换"的判断依据
- 持有层规则（个人策略，写入文档不进引擎）：已持有者仅"严重"级警报才考虑换；
  仅排名小幅后移不动
