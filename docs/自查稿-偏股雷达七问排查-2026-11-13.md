| 已覆盖 | 只碰表面 | 缺失 |

## 2. Q2 回撤控制进评分/考卷/门槛了吗？

**判定：如实回答——没有。现状是"只做展示"，且这是11-12的拍板（风险不做门槛）+ F4 证伪（三起点负IC）。本轮补了该补的验证。**

- 在榜计分基金5年回撤：**中位40%、p75=47.9%、>60%者6人、>75%者0人**；
- **回撤持久性验证（伪前瞻，池级）**：
  - E2(回撤>60%)：cut组未来回撤 **38% vs kept27%（T0）/40% vs28%（Tm）**——持久性确认；
    但 cut 组未来**收益也更差**（-11.0 vs-5.3 / +6.3 vs+9.9）→ 切它=用收益换安全；
  - E3(回撤>75%)：cut n=11，未来收益 **-16.6% vs -6.1%（T0）、-12.4% vs +9.5%（Tm）**
    **且**未来回撤47% vs29%——**收益与回撤双差，唯一"切了两头都赚"的回撤规则**。

**方案（不推翻拍板，给调和）**：
- **维持**：回撤不进评分（F4=0）、不进考卷——11-12拍板保留；
- **P1 新增尾部护栏**：5年回撤 **>75% → 出局**（类比"断档即时出"的资格性质，
  不是排序因子）。依据=E3双差验证；当期在榜0人命中（无误伤），纯未来保护。
  阈值60/70/75需在落地时做敏感性对照（P1验收项）。

## 3. Q3 风格分类与同格可信吗？降级误伤/漏伤？小格够用吗？

**判定：分类框架已覆盖（含审计与降级），但降级规则是"只碰表面"——15%阈值拍的、无金标准、单向；小格样本明确不够。**

- 已覆盖：名字分桶被审计否决（一致率45.9%）→ 相关性分类；前10持仓校验降级1511只（均衡925→2434）；
- **降级的误伤/漏伤无法直接量化**（没有全量持仓=没有真值标签）→ 本轮用**相关性余量作proxy**：
  在榜30人余量<0.10（低置信标签）；降级只降不升（单向偏置：真倾斜但前10分散者被误降）——
  **这是当前方法最大的已知盲区**；
- **小格明确不够**：降级后周期103只、新能源123只 → 同格 top25% 只有26/31只，
  ps 步长≈4pp，考卷"3年进前25%"在小格上是"进前8名×3年"，名次噪声大（在榜23人在格<150的格里）；
- 标签时间稳定性（窗口平移下的翻转率）**未测**。

**P1 方案**：
1. **小格合并**：格样本<150 → 并入三类格（成长/价值/均衡）取分位，或把同格最小样本从10提到50。
   数据需求：现成（feat 格计数）。验收：小格成员考卷名单的两期 Jaccard 稳定性提升、
   小格成员未来同格排位的方差下降。风险：合并稀释风格隔离（三类内混风格）——需对照检验9信号强度。
2. **降级阈值敏感性**：10%/15%/20% 三档重跑 → 对比降级人数、标签余量分布、考卷名单变动（成本：仅重算特征+考卷）。
3. **标签 churn 测试**：相关窗口平移±30天重算分类 → 翻转率（验收：<5%翻转才认为标签稳定）。
4. 全量行业数据源攻坚见 P2（它是降级金标准与漂移检测的共同前提）。

## 4. Q4 评分因子/权重/缺因子公平吗、稳健吗、可解释吗？

**判定：权重推导与证伪链已覆盖；缺因子问题当期实测为零；F3 的 β=1 假设是实质缺陷（本轮已量化）；多重检验校正缺失。**

- 已覆盖：LOOCV-IC 三起点定权（W3 全胜等权）、F4 三起点负IC证伪归零、
  缺因子固定分母与验证脚本逐行同款、**当期在榜者缺因子=0人**（分母问题实际未发生）、
  W1/W2/W3 对照、检验18-20；
- **只碰表面**：F3 用"单代理且β=1"——对 β≠1 或多风格暴露的基金系统性失真。
  **本轮双起点回测**：6代理β尺度化 F3/F5 变体（W3s）vs 现产（W3r）对未来同格排位 IC：
  T0 **+0.009 vs +0.006**、Tm **+0.021 vs +0.006**——尺度化**两起点均不劣、Tm 显著更好**；
- **缺失**：
  - F6（质地=任期+从业分位）**未做消融**（它在 Tm 起点 IC 最高+0.023，是巧合还是真贡献？未验证）；
  - **多重检验**：0.35相关阈值/前25%/均排70/15%降级/2亿/-5%/50%·30%仓位——
    多数来自单次回测或本轮自定，**未做±20%敏感性网格**，存在"阈值过拟合这段历史"的风险；
- **IC 口径对账（诚实披露）**：本轮全样本伪前瞻 IC≈0（W3r +0.006），远低于检验18的+0.053~0.180——
  差异来自**未来度量不同**（检验18=未来逐年同格排位均值、两榜样本；本轮=单段累计收益在起点格内的分位、全池）
  与**样本不同**（闸后小样本 vs 全池）。两者都不支持"评分能高精度预测"，与检验18的
  "榜内随机基线已高、48%噪声天花板"披露一致：**评分价值=排序稳定+公平，不是预测精度**。

**P1 方案**：① F3/F5 尺度化换装（验收=换装后重跑检验18/19/20三套全过且前列稳定性不低于现版；
风险=格内公平可能被多β噪声扰动，需检验20复测）；② 关键阈值±20%敏感性网格（验收=结论不翻转的阈值清单）；
③ F6 消融（三起点IC单独测）。

## 5. Q5 考卷/双十直通/绝对门槛/复评自洽吗？

**判定：机制层自洽（状态机69项测试、双周确认有检验17依据、毕业87%有检验16依据）；
但存在一处实质矛盾——"双十全部上榜" vs "深亏不该上"，本轮已用数据调和。**

- **矛盾与调和（本轮 P0-G2）**：双十免考卷免0%门槛后，20名计分基金负收益者在榜——
  用户先拍"全部上榜"、后指令"不合理要排除"。数据裁决：
  **深亏<-5%组伪前瞻两起点都显著更差**（T0 cut-8.6% vs kept+1.9%；Tm +1.1% vs +31.5%；
  池级 E1<0 同向），而检验20保护的是"**格内高分**的逆风者"——被切4人中3人评分<42（格内也弱），
  不属于检验20的保留对象。**调和方案 = G2 硬线对双十同样生效**：深亏基金一律不作计分依据
  （陶灿/朱少醒/孙伟因此出榜；程洲的-6.9%国泰大农业被剔出计分集、换用其≥-5%的另一只
  过考基金留任、分数由85.5降至约52——**展示的计分数字必然≥-5%**）。
  "全部上榜"的边界由此修正为"除深亏基金"。
- **边界如实披露**：89名双十中13名因 L1 资格/数据不全未入（无5年基金=无可展示的5年指标）；
- **双十年化资格是动态的**：从业年化每期用最新净值重算，跌破10% → 失去直通 → 下期按考卷走（已实现）；
- **复评节奏自洽**：三硬闸与考卷失败同走"先滤后取 + 首过不出双周确认"（不因API抖动冤枉人：
  仓位/规模缺数据一律 fail-open 跳闸）；
- **待观察**：双周保护让"真掉队"多留1-2周——与"确实不行如实换"的延迟权衡已有检验17量化（测量噪声>能力变化）。

**三闸的执行语义（重要）**：与 S3/S4 一致，**闸是基金级**——经理只要还有**一只**过考基金
同时通过三闸即可在榜（其计分基金=过闸基金中分数最高者，**展示的计分基金必然全过三闸**）；
三闸把某只基金从其候选集中剔除时，若其还有别的过闸基金则**换代表作降分留任**、
全部基金都被剔才出榜。因此"旗命中人次"≠"出榜人数"：
- G1 旗命中29人 → **6人经其他≥2亿合格基金留任**（肖世源/张琦/栾江伟/陈鹏/陈一峰/吴渭，计分基金随之更换）→ 实出榜23；
- G2 旗命中4人 → **程洲经另一只≥-5%基金留任**（计分基金由-6.9%的国泰大农业换为≥-5%者、
  分数由85.5降至约52）→ 实出榜3（陶灿/朱少醒/孙伟）；
