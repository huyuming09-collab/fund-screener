## 二、文件归属判定表

| 新增的东西 | 放哪 | 例子 |
|---|---|---|
| 新指标计算（纯函数） | `fundscorer/metrics.py` + `tests/test_metrics.py` | 波动、回撤、修复天数 |
| 新权重/阈值/红线 | `fundscorer/config.py`（**属产品决策，先问用户**） | 卡片权重、S1~S5 阈值 |
| 新数据源 / 抓取字段 | `fundscorer/sources/` 或 `data.py` | 非货规模、经理信息 |
| 新池 / 新分类 | `config.py` 的 `CARD["categories"]` + `docs/` 说明文档 | 债指基金（现被开关关闭） |
| 筛选逻辑变更 | `screen.py` + `docs/07 或 09 或 10` 同步 | 两段式条件调整 |
| 网页展示字段 | `cards.py`（字段契约）+ `web/index.html`（渲染）**两处必须同步** | 榜单新列 |
| 新结论级文档 | `docs/NN-主题.md`（编号顺延，见命名规范） | 11-三池重构 |
| 深度推演 / 完整计算过程 | **不入库**，本机 `运营/素材库/方法论/NN-主题.md` | 04 全市场核验、05 因素回测 |
| 对外文案、配图、选题、台账 | **不入库**，本机 `运营/`（期次包制） | 小红书、公众号 |
| 一次性验证脚本 | 用完即删，或放 `.shots/`；**不进 `scripts/`** | Playwright 目检 |
| 新增第三方依赖 | 原则上不加；确需则改 `requirements.txt` 并在 commit 说明 | — |

## 三、命名规范

## 四、模块状态表（活跃 / 休眠 / 研究）

| 模块 | 状态 | 说明 |
|---|---|---|
| `config.py` `data.py` `metrics.py` `scorer.py` | 🟢 活跃 | 主链核心 |
| `rank.py` `screen.py` `batch.py` `pipeline.py` `cards.py` | 🟢 活跃 | 周更主链 |

| `indexfund.py` + `tests/test_indexfund.py` | 🟡 休眠 | 由 `config.INDEX["enabled"]` 总开关控制（**现为 False**）。关闭时：universe 排除指数型、F10 复判跳过、pipeline 不走指数候选分支。**代码与测试全保留**，打开开关即恢复 |
| `backtest.py` `backtest2.py` | 🔵 研究 | 历史回测与目标函数预注册回测，**不接入周更主链**，无单测；产物写 `data/backtest_*` |
| `scripts/content_digest.py` | 🟢 活跃 | 周更 → 本地运营素材包；**无单测**（见 STATUS 已知问题） |

> 判定口径：🟢 主链每周都会跑到；🟡 代码在、链路被开关切断；🔵 独立脚本，人工按需运行。

## 五、数据流一句话

```
天天基金/中债指数 (data.py, 缓存 data/cache + data/nav_full)
   → rank.py 全市场评分 → data/metrics_cache.pkl（6,901 只池指标）
   → pipeline.py 逐池刷新 → screen.py 两段式筛选 → scorer.py 筛后评分
   → cards.py 三件套导出 → data/top20.json + data/screen_report.csv + web/data.js
   → web/index.html 渲染（人读）／ ?export=<pool> 社媒榜单图
   → scripts/content_digest.py 另出一份本地运营素材包（不入库）
```

任一池失败 = 整体失败、产物不动，线上保持上一期数据。
