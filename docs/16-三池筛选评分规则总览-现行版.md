# docs/16 · 三池筛选评分规则总览（现行版 v5.9）

> **本文是三池（中短债 / 长债 / 固收+）筛选与评分现行规则的唯一总口径**：所有数值与 `fundscorer/config.py`
> 同步，任何改动须走 `docs/15 §2` 变更流程（拍板 → 证据 → 四门验证 → 记账）。历史设计稿
> （docs/07/09/10/01/11）仅作沿革参考，与本文冲突以本文为准。
> **数值基准**：v5.9 代码（2026-10-21）；漏斗实例为 2026-10-21 管线实测。分数 = 池内相对评分，
> **不同池的分数不可横向比较**。版本沿革与账本见 `docs/15`。

## 0. 体系速览

| 池 | 显示名 | 池口径 | 池版本 | 周更 |
|---|---|---|---|---|
| `short_bond` | 中短债 | 债券型·短久期主动+指数（指数分支见附录 A） | v5.9 | 每周五 23:00 |
| `long_bond` | 长债 | 债券型·中长久期主动+指数 | v5.9 | 同上 |
| `fixed_plus` | 固收+ | 偏债混合 + 混合二级 + 混合一级（FOF 排除，v5.4） | v5.8 | 同上 |
| `index` | 指数 | 债券指数口径已实现，`INDEX.enabled=False` 关闭中 | — | 关闭 |

**主链路**：全市场 → 公司规模排除（非货 <300 亿剔除，无映射保留）→ 归池（A/B/C/D 份额合并计算）→
**S 硬闸** → **P 性能闸** → **池内评分**（分位/门槛/质地绝对分 + 团队系数）→ **红线 R7 封顶 60** →
分数降序取 TOP20（排序取 A 类份额）→ 环比对照 → 三件套（`top20.json` / `screen_report.csv` / `web/data.js`）。

**评分公式**（`scorer._score_one`）：

```
raw = Σ(子项分/100 × 权重)          # 经理块三键子项分先 ×团队系数
score = raw × 100 ÷ earned_weight   # earned_weight = 有数据因子的权重和（缺失因子归一吸收）
红线触发 → score 封顶 60
```

**评星现状**：`STARS` 配额逻辑保留在管线但**显示层不展示**（用户已定现阶段不做自评星级，悬置待拍）；
晨星评级作为因子 `ms_rating` 独立计分，与自评星级无关。清洗口径：单日 |收益| >20% 判坏点中和。

## 1. 中短债池（`short_bond`，v5.9）

### 1.1 筛选（`SCREENS["short_bond"]`）

| 闸 | 现值 | 语义 |
|---|---|---|
| 前置 | 公司非货 ≥300 亿 | `COMPANY_SCALE`，全市场级剔除 |
| S1 | 合并规模 ≥5 亿 | A/B/C… 份额合并，不单独算 |
| S2 | 经理从业 ≥5 年 | 现任基金经理 |
| S3 | 现任经理任本基金 ≥1095 天 | 3 年 |
| S4 | 成立 ≥5 年 | 保证近五年数据完整 |
| S5 | 近 5 年单日涨幅 ≤1% | 异常涨幅剔除（长债 2%、固收+ 5%） |
| P1 | 四项分位均值的池内分位 ≥45% | 四项 = 近 5y/3y 收益与回撤的池内分位 |
| P2 | 完整自然年收益分位中位 ≥55% | ≥4 个完整年（年内 ≥120 点且有上年基数）、单年池内 ≥30 只 |

### 1.3 打分机制（本池要点）

- **分位方向**（`PERCENTILE_METRICS`）：ret/lvi/winrate/q_excess/q_win/products/calmar/sharpe → higher；
  mdd/vol/repair/rank_stab → lower；fee 同池分位越低越好（`percentile_score`）。
- **风险门槛制**（`RISK_THRESHOLD`，池样本 ≥20）：mdd 三窗口与 vol ≤池均值×1.5 → 满分 100，≥×4.0 → 0，中间线性。
- **yearly_5y**：逐年池内排位的绝对规则分（`_yearly_score`）。
- **质地绝对分档**（`_quality_scores`）：成立 5 年→100/3 年→60；任期 5/3/1 年→100/70/30；从业 8/5/3 年→100/70/40；
  晨星 5→100、4→80、3→60、2→40、1→20（缺→50）；费率池内分位。
- **团队系数**（三池统一）：现任满 3 年共管 1/2/≥3 人 → 经理块三键（tenure/career/products）子项分与贡献 ×1.00/1.05/1.10，缺失回退 1.00（直觉规则已标注）。
- **红线 R7**（触发封顶 60）：R7-1 任职 <180 天；R7-2 规模 <5000 万；R7-3 回撤双条件（阈值 0.3%，mdd_1y 对池中位的系统性/非系统性双分支）；R7-4 近 1 年单日最差跌幅 >max(3×中位绝对, 0.10%) 且 20 日未修复一半。

## 3. 固收+池（`fixed_plus`，v5.8）

### 3.1 筛选（`SCREENS["fixed_plus"]`）

S1~S5 同两债池（S5 = 单日涨幅 ≤**5%**），外加固收+专属风险预算与性能闸：

| 闸 | 现值 | 语义 |
|---|---|---|
| S6 回撤闸 | 普通经理 ≤10%；R3 精英 ≤12% | 近 5 年最大回撤；精英判定同评分端 R3 语义（v5.3 分级，v5.8 R3 放宽） |
| S7 波动带 | 2.5% ≤ 近 5 年年化波动 ≤8% | 下限 2%→2.5%：挤回"行为像纯债"的伪增强（纯度优先） |
| ~~S8 收益上限~~ | **已删除**（v5.3） | "不追高收益"≠"限制收益" |
| P1 / P2 | ≥45% / 中位 ≥55% | 同两债池阈值，百分位基准 = 固收+合并全池 |

2026-10-21 实测漏斗：合并 1329 → S1 509 → S2 391 → S3 274 → S4 226 → S5 209 → S6 151 → S7 126 → P1 109 → P2 82。

### 3.2 评分权重（`FIXED_PLUS_WEIGHTS`，合计 100）

| 分区 | 因子（权重） | 小计 |
|---|---|---|
| 风险（v5.8 收益↑稳健↓） | mdd_1y 9 / mdd_3y 7 / mdd_5y 5 / vol_5y 10 / repair_5y 0 | 31 |
| 风险调整收益（v6 同族择优） | calmar_5y **25** / sharpe_5y 0（展示） | 25 |
| 胜率与运营 | winrate_m_5y 9 / q_win_20q 8 / fee 6 | 23 |
| 经理块（×团队系数） | mgr_tenure 4（资深档）/ mgr_career 4 / mgr_products_ann 4（债券口径过滤） | 12 |
| 机构占比 | inst_ratio 2 | 2 |
| 结构块 | ret_5y 2（**反向证据已标注**：valid IC −0.208 直觉规则）/ fund_scale 4（U 型）/ ms_rating 1 | 7 |
| 质地与其余 | rank_stab 0 / age 0 / excess_5y、ret_1y/3y、yearly_5y、q_excess_20q、company_scale、sharpe 均 0 | 0 |

### 3.3 打分机制（与债池差异点）

- **回撤分档**（`FIXED_PLUS_MDD`，覆盖纯分位）：三窗口 mdd ≤4% → 满分 100，超出线性至 0；
  归零上限 = **R3 容差**——精英经理 15%、普通 10%（`QUALIFIER.tol_*`，warn 档 13%/8% 为提示带）。
- **vol** 同债池门槛制（≤均值×1.5 满分、≥×4.0 归零）。
- **R3 经理资质**（`_manager_qualified`）：可比年 ≥3；逐年被超过 >50% 的年数 ≤1（v5.8 放宽，一年失手不否决）；
  平均被超过 ≤33.3%（长期跑输一票否决）。同一判定同时驱动 S6 分级与评分容差。
- **资深分档**（v5.8 专属）：任期 10/5/3/1 年 → 100/85/70/30；从业 12/8/5/3 年 → 100/90/70/40（债池维持旧档）。
- **机构占比渐变**（v5.6）：20%~90% 满分；>90% 线性 100→20（每 1 个百分点 −8）；10%~20% → 50；<10% → 30。
- **规模 U 型**（v5.6，4 分）：10~100 亿满分档；<0.5 亿 0；≥500 亿 65。**公司规模**当前权重 0。
- **calmar** = ret_5y/mdd_5y 的池内分位（分子分母结合，对应"风险预算内卡玛最优"）。
- **红线 R7**：R7-1~4 同构（单日下限 **1.5%**；R7-3 用 S6 通过的回撤上限做阈值）；**R7-5 深回撤 240 天未修复**（固收+专属）。

## 4. 公共口径与纪律（引用规则时必带）

1. **分数不可跨池比较**；所有分数标注「池内相对评分」。
2. **`*_5y` 字段须配 `nav_years` 闸**：历史不足 5 年时字段退化为全期计算（AGENTS §4-2）。
3. 数据不足的因子不参与 earned_weight 归一；小样本池（<5 只）打旗标、分位仅供参考。
4. **R8 长跑修正（`ADJUST`）配置保留但现行管线未接线**（无代码引用，勿当作现行规则）。
5. **展示层（均不计分）**：风格标签四象限、经理占席 ×N、详情任期卡玛、净值走势、阶段收益、夏普展示（无风险利率 1.5%）。
6. LVI 口径：风险代价 = 0.6×最大回撤 + 0.4×下行波动（下限 0.2%），转池内分位。
7. 归池、筛选、评分、红线、TOP20 截取的实现入口：`batch.py` / `screen.py` / `scorer.py` / `pipeline.py`。
