# 09 · 长债筛选与评分（摘要）

> 版本：v1.0（2026-10-17 实现） · 参数：`fundscorer/config.py → SCREENS["long_bond"]` / `POOL_WEIGHTS["long_bond"]`
> 定位：长债池与中短债**同构**的"先筛后评"体系；各池 TOP20，页面分类 tab 切换。
> **完整设计推演**（长债单日涨幅分布、124 件事件反向检验、试算漏斗与锚点样本验证）在
> 公众号「班马成长日记」发布，未随仓库保留；本文件只留结论与工程口径。
>
> **2026-10-19（v5.4）**：池显示名由"中长债"改为 **长债**（池 id `long_bond` 不变，
> `rank_history` 与分数可比性不受影响）。同批变更见 [`docs/11-三池重构与指数基金口径.md`](11-三池重构与指数基金口径.md)：
> ① **混合一级按行为分层** —— 近 5 年波动 <2.5%（`vol_5y_min`）归本池、否则归固收+；
> ② **债券指数走独立口径** —— 不看经理（跳过 S2/S3）、S4 放宽到 3 年、
> 按**近三年业绩**与主动榜穿插插值排名、同一跟踪指数最多 2 只（文档 11 §三）。

## 一、结论

- 风险哲学差异（用户口径）：**中短债 = 纯求稳；长债 = 稳为底 + 稍偏收益**，
  后者由评分卡 IC 池权重倾斜落地，而非另起炉灶重训权重。
- 筛选标准与中短债同构（S1~S5 + P1~P2 两段式），**仅 S5 的单日尖峰阈值池别化：中短债 1% / 长债 2%**。
- 评分卡直接复用 v5.1 长池 IC 权重：目标函数预注册回测的长池验证段显示现行权重与最优候选差异在噪声内。

## 二、筛选阈值（`SCREENS["long_bond"]`，945 只合并基金起点）

| 条件 | 阈值 | 与短债差异 |
|---|---|---|
| S1 合并规模 ≥5 亿 | 同短债 | — |
| S2 现任经理从业 ≥5 年 | 同短债 | — |
| S3 现经理任本基金 ≥3 年（1095 天） | 同短债 | 约束主力 |
| S4 成立 ≥5 年（近五年数据完整） | 同短债 | — |
| **S5 近 5 年无单日涨幅 >2%** | **长债专属** | 短债 1% |
| P1 四项分位均值的池内分位 ≥45% | 同短债 | — |
| P2 完整自然年收益分位中位 ≥55%（可比年 ≥4） | 同短债 | — |

百分位基准（P1/P2）= 长债合并全池（含未过硬条件者）；排序按 A 类份额的 v5.2 分数降序
（无 A 类用代表份额），与短债口径一致。

## 三、评分（复用 `PURE_BOND_WEIGHTS_LONG`，v5.1 不改）

- **稳为底**：风险块 15 分门槛式（回撤 5/3/2 + 修复 4 + 波动 1）+ 红线按池参数
  （长债：近 1 年回撤 >1.5% 双条件封顶；单日跌幅下限 0.30%）。
- **稍偏收益**：IC 池 61 分向收益族倾斜——ret_1y **9.97**（短债 7.69）、ret_3y 8.82、
  lvi_3y 8.27、winrate_m_5y **4.25**（短债 0.46）、fee 3.51（短债 8.91）。

## 七、诚实披露

- S1（规模）与 S5（单日尖峰）是可投性/数据健全性排除闸，**不是 alpha 因子**：
  回测面板无规模与尖峰字段，不做前瞻收益回测；依据为经济不可能性论证与分布分析。
  P1/P2 的构成因子已由因子 IC 回测背书（回测细节见公众号）。
- 某池候选 < TOP20 → 仅告警不自动放宽（放宽需人工评估 `SCREENS`）。
- 长债首期无环比，第二期起才显示 ↑↓/新增。
