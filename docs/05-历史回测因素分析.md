# 05 · 历史回测因素分析（v5.0 权重修订依据）

> 目的：不再纯凭主观设定各因素权重，而是用**滚动时点回测**量化每个因素对未来
> 1 年持有胜率的预测力，据此提出 IC 加权候选权重，与现行手工权重对照验证。
> 本文是评分标准（docs/01）权重章节的**实证依据**，供人工审定。

## 1. 回测设计

| 项目 | 设定 |
|---|---|
| 节点 | 每半年末 2019-06-30 ~ 2024-06-30，共 **11 个** |
| 时点纪律 | 所有因子严格截断到节点 T（净值、基准、经理任期均无前视） |
| 样本门槛 | 节点 T 处历史 ≥3 年（对齐星级门槛）；实际入样 17,222 基金节点 × 2,769 只基金 |
| 前瞻持有 | T → +6月 / +1年 / +2年（主口径 1 年） |
| 胜负定义 | 前瞻收益 > 同池同节点**中位数**（池内相对胜率，用户确认口径） |
| 因子集 | 18 项：净值窗口类 + 质地类；**晨星/机构比/规模/经理全产品年化不参与**（不可无偏回溯） |
| 经理任期/从业年限 | 按任职起始日回推到节点 T（近似准确） |
| 评分函数 | 复用生产 `scorer._score_one`：分位/门槛/红线逻辑与生产完全一致 |
| 训练/验证 | 前 7 节点（2019H1~2022H1）生成 IC 权重；后 4 节点（2022H2~2024H1）独立验证 |

**已知局限（诚实披露）**
- **幸存者偏差**：fundcode_search 只返回存续基金，已清盘基金不在样本内，长期胜率可能被高估。
- 重叠窗口（相邻节点共享大部分历史）使 t 值偏乐观，本文以"训练/验证同号"作为稳健性主判据。
- 固收+ 池样本约为纯债池的 1/3，IC 显著性天然更弱。

**读法要点**
1. **动量/持续性类（ret_1y/3y/5y、excess、q_excess、lvi、yearly_5y）在纯债池全面有效**，
   IC +0.21~+0.37，t 值 6~14，是预测未来胜率最强的一族；其中 yearly_5y（逐年中位对比）
   单调性最漂亮（Q1 0.32→Q5 0.65），**"年年都在同类中位以上"比"某窗口收益高"更可靠**。
2. **费率 IC 出人意料地强**（短债 +0.31）——低费率基金未来跑赢概率明显更高。
3. **风险类指标（回撤/波动）IC 为负**（方向对齐后 −0.20~−0.33）：这不意味着"回撤越大越好"，而是分层胜率（§3）显示其**单边线性关系不成立**——回撤最小的 Q1 和最大的 Q5 胜率都偏离中位，中间段平坦。这正是"门槛式打分"（≤1.5×池均值满分、线性扣分）优于纯分位的实证依据。
4. **经理任期 IC 为负**（−0.14）：任职久的经理未必未来 1 年更强；但经理维度的价值在于**排除风险**（新人、短期业绩不稳），见 §5 处理建议。
5. **固收+ 池几乎没有显著 IC**（|IC|≤0.06，t 值小、训练/验证频繁翻号）：权益敞口主导未来收益，净值类因子预测力弱——固收+ 的评分更应依赖"回撤纪律 + 经理资质"而非动量。

**⚠️ 关键发现：风险类因子"反向"的正确解读**

读表口径：Q1 = 按"低=好"方向排序后的最差组，即**回撤/波动最大**的组；Q5 = 回撤/波动最小的组。

- 短债池 vol_5y：Q1（波动最大）胜率 0.610 → Q5（波动最小）胜率 0.254；
- 中长期池 mdd_1y：Q1（回撤最大）胜率 0.667 → Q5（回撤最小）胜率 0.300。
- 即：**在本回测窗口内，历史风险越高的基金，未来 1 年跑赢池内中位的概率反而越高。**

**成因**：2019~2024 为持续债牛（利率趋势下行）。回撤/波动大的债基往往久期更长或信用下沉更激进，
收益基数更高，在利率下行周期中持续跑赢；低波动组多为短久期理财型基金，收益天花板低。
**"跑赢池内中位"的胜率口径本身就会奖励承担利率风险的基金。**

**这对评分标准意味着什么（核心结论）**：
1. **不能**据此把风险因子改成"越大分越高"——该现象是利率单边下行的**状态依赖**产物，
   一旦利率反转（如 2016 底、2020 中的收益率快速上行），高久期/下沉组将反向崩塌。
   回测窗口内没有经历完整的利率上行段，风险因子的保护价值在本窗口**天然无法被观测**。
2. 若把风险维度权重降为 0（纯 IC 加权的做法），等于把组合押注在"债牛永续"上——**不可采纳**。
3. **门槛式打分的形态恰好匹配实证**：风险因子五分位关系非单调（两头高中间低），
   纯分位排序没有信息量；而门槛式（≤1.5×池均值满分→超出线性扣分→×4.0 归零）只惩罚**尾部风险承担者**，
   不给"最低波动组"额外奖励——避免了在无信息区间做错误排序。
4. 风险维度的真实角色是**排除尾部 + 跨周期保险**，而非预测收益，因此应保留为固定配额（保底约束），
   其权重不参与 IC 加权——这正是 §6 混合方案的依据。

## 5. 组合验证：三个权重方案在同一打分器下对比

三方案均走**生产同一套** `_score_one`（门槛分、红线封顶、缺失数据按有权重归一），只换权重表：

- **a = 现行权重**（回测可回溯子集，88 分）：即 v5.0-r2 手工权重；
- **b = 纯 IC 加权**：88 分全部按训练段方向对齐 IC（max(IC,0)）分配——完全数据驱动，**风险/稳定性/经理权重全部归零**；
- **c = 混合 B（推荐）**：风险块（回撤+波动+修复）与稳定性（rank_stab）、经理块（任职/从业/全产品年化）、晨星评级**保留现行固定配额**，其余 61 分按 IC 分配，单因子上限 15 防动量过度集中。

**表 5-1 · 前 20% 组合持有 1 年跑赢同池中位的胜率（训练段 7 节点 / 验证段 4 节点）**

| 段 | 池 | a 现行 | b 纯IC | **c 混合B** |
|---|---|---|---|---|
| 训练 | 短债 | 0.652 | 0.666 | **0.683** |
| 训练 | 中长期 | 0.653 | 0.672 | **0.672** |
| 训练 | 固收+ | 0.479 | **0.616** | 0.554 |
| 验证 | 短债 | 0.495 | **0.537** | 0.532 |
| 验证 | 中长期 | 0.505 | **0.531** | 0.517 |
| 验证 | 固收+ | 0.542 | **0.602** | 0.570 |
| **全部** | 三池汇总 | 0.565 | **0.617** | 0.601 |

超额收益（相对池中位，年化）同向：a 0.2% / b 0.7% / c 0.4%；现行权重后 20% 组合胜率仅 0.398
（说明现行分数对"差基金"的识别是对的，问题在"好基金"排序不够强）。

**读法**：
1. **b 全面最强**（+5.2pp vs a）——纯数据驱动确实最贴合历史；但它把风险维度打到 0，
   等于对"利率永续下行"下注，跨周期保护归零（§3 已论证该现象的状态依赖性）。
2. **c 在保留全部风险/经理/稳定性配额的前提下，仍拿到 +3.6pp**（0.601 vs 0.565），
   验证段三池全部优于现行；与 b 的差距（1.6pp）可视为"跨周期保险的保费"。
3. 固收+ 池 b/c 都明显优于 a：现行固收+ 权重里动量类（ret_5y/excess_5y/yearly_5y/lvi_5y）
   合计 50 分，但这些因子在固收+ 池 IC 为负或零——现行权重在固收+ 上是**负优化**，
   c 方案把配额让给唯一有效的 ret_1y（24 分）后立即改善。
4. 固收+ 的 c 方案因正 IC 因子不足（容量不足），ret_1y/age/lvi_3y 三项按 IC 比例突破了
   15 分上限（24.2/16.9/15.9）——固收+ 池因子证据太弱，宁可集中于唯一有效因子。

## 6. 结论与权重建议

### 6.1 因子层面（已被回测证实）

| 结论 | 证据 |
|---|---|
| ① 动量+持续性是纯债池最强预测族 | IC 0.21~0.37，t 6~14，训练/验证同号 |
| ② yearly_5y（逐年跑中位）单调性全场最佳 | Q1 0.32 → Q5 0.65，两池同构 |
| ③ 低费率显著预测未来胜率 | 短债 fee IC +0.31，Q1 0.32→Q5 0.58 |
| ④ 风险类因子"反向"是债牛状态依赖 | 高风险组跑赢但属利率下行红利；反向在训练/验证段同样稳定 |
| ⑤ 经理任期/从业年限预测力弱或反向 | IC −0.14~+0.01，分层非单调；经理价值在排除风险而非选优 |
| ⑥ 固收+ 池因子几乎全部失效 | 仅 ret_1y 稳定（同号），其余 11/20 项翻号 |

### 6.3 保留不变的原则

- 风险门槛打分（≤1.5×池均值满分 → ×4.0 归零）：**不动**——实证表明风险因子无排序信息量，
  门槛式只做尾部排除，与其信息结构匹配；
- 红线 R7-1~5、公司规模排除 R10（<300亿）、星级体系：**不动**；
- 经理维度维持 20 分：回测证实其无选优能力，但用户设定的"经理稳定性=风险约束"角色
  与 R7-1（新人经理封顶）配合，继续保留。
