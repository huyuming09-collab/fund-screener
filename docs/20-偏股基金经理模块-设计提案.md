# docs/20 · 偏股基金经理模块：设计提案（待用户拍板）

> **触发**：用户 2026-11-11 提出偏股模块四点要求：
> ① 时间周期拉长，设**优秀经理阀**，允许优秀经理短期跑输；
> ② 按**风格分池**（成长 / 价值 / 均衡），因为风格周期切换会让某风格整体持续跑输；
> ③ 评估**风格稳定性**——价值型经理追涨科技、医药经理追科技，都不行；
> ④ 展示以**基金经理为主体**（不以单只基金为主体），详情页放几只代表作。
>
> **状态：提案，未落地。** 所有阈值/权重均为占位，落地前需按 §9 逐条拍板；评分权重须经回测检验（沿 docs/18 方法），不拍脑袋。

## 1. 模块定位

| | 现有三池（债） | 偏股基金经理池（新） |
|---|---|---|
| 评估主体 | 基金（份额级） | **基金经理**（经理级聚合） |
| 核心风险 | 利率/信用、回撤 | 风格逆风、风格漂移、能力圈失效 |
| 排序逻辑 | 池内相对评分 | **风格子池内相对评分**（成长只和成长比） |
| 短期跑输 | 直接反映在分数 | **不直接进分**，走"优秀经理阀"豁免逻辑 |

底层依据（调研结论，见对话记录与来源链接）：
- **基金经理能力有持续性，基金业绩没有**（华泰金工 IC/IR 回测 + 海外文献）→ 以经理为主体排序成立；
- 风险指标（回撤/波动）**预测回撤不预测收益**（docs/18 §2 同结论）→ 回撤只做闸与哨兵，不做主排序；
- 过去 1 年收益/Sharpe/Calmar 长期排序有效性弱 → **短期业绩不进核心分**。

## 2. 总体架构：三段式

```
S 硬闸（身份与数据） → 风格子池内评分（长窗为核心） → 优秀经理阀（短期跑输豁免）
```

### 2.1 S 硬闸（2026-11-11 用户拍板，已落地 `fundscorer/eqgate.py` v1）

> 拍板背景：用户明确"**不需要筛选出很多基金经理，只需要最稳定的那一批**；主动基金风险大，
> 没经过时间洗礼的短期业绩不值得看；不筛潜力股，要资深老将——投资本身就该少量"。
> 故年限整体上调，结果少是预期不是缺陷。

| 闸 | 内容（拍板值） | 意图 |
|---|---|---|
| S1 | 池边界：**股票型 + 混合型-偏股 + 混合型-灵活 + 混合型-平衡**（当前 9,449 只） | 剔除指数/债/QDII/FOF/偏债 |
| S2-A | 经理从业**双通道**：**>10 年全部入围**；**>6 年且 ≤10 年须同类近5年年化超额前 20%**（2026-11-12 由 10% 放宽）；≤6 年出闸 | 老将直通；中生代只做**初筛**，严格线留给后续评分阶段 |
| S2-B | B 通道分位格 = **类型 × 相关性风格**（2026-11-12 从"名字关键词桶"升级，见下） | 修复名字分桶残留的风格偏差 |
| S2-C | **A 通道垫底底线（2026-11-12 全量审计后新增）**：同格收益排位**后 10% → 出局**（pctl 缺失不砍） | A 通道"直通但去尾"：不设线会放进 69.3% 五年负收益、最差 -21.5% 年化的"老将"；5 年同风格持续垫底 ≠ 短期跑输 |
| S3 | 现任经理**任本基金 ≥5 年**（1825 天，与债券池 1095 同 365/年口径） | 5 年业绩可完整归因到现任经理 |
| S4 | 基金**净值 ≥5 年** | `nav_years` 闸同款语义，防半截数据 |
| S5 | 在管规模闸（**未实施**，数据已备：通过基金中位 3.1 亿、<1 亿 344 只占 27%，待拍板） | 规模魔咒 + 清盘风险 |
| S6 | 风格判定数据闸（风格分类已并入 S2-B，见下） | ~~评分阶段~~ 提前落地 |

**风格分类引擎（S2-B 的核心，2026-11-12 升级）**：
- **为什么不用名字**：审计实锤——名字分桶与独立相关性分类**一致率仅 45.9%**（名字是营销标签）；
  且"其他/均衡"大桶（占通过者 80%）内部按真实风格拆开后**偏差原样存在**：桶内 p80 达标率
  周期 31% / 科技 27% / 价值 24% / 医药 15% / 新能源 6% / **消费 0%（135 只全灭）**。
- **实现**：净值 5 年周频**超额收益**（剔共同市场 beta）vs 6 个风格代理指数（全指信息/全指医药/
  主要消费/中证新能源/中证红利/中证A股资源产业，全部本地 eqcs 缓存、5y 覆盖已核）相关，
  argmax ≥0.35 归类，否则"均衡"；代理缺任一 → 整体回退名字桶。
- **性质**：docs/20 §3 方案A（净值回归）的前置简化版提前落地；只读本地、无网络，结果缓存 7 天
  （5y 窗口下风格极稳定）；持仓级判定仍是 v2 升级方向。
- 分层回退：类型×风格格 ≥10 只 → 同风格全池 → 类型（与分位、pctl 同层级）。

**口径细则（实现即文档，见 `eqgate.py` 模块头）**：
- **"同类" = 类型 × 风格桶**（2026-11-12 用户质疑"是不是全筛成科技了"后加入）：
  基金名关键词粗分 7 桶（科技/医药/消费/新能源/金融价值/工业/其他均衡），B 通道分位在
  **同类型同风格桶内**取（消费和消费比），样本 <10 只逐层回退（同桶全池 → 类型）。
  **数据依据**：类型内比较系统性偏向近 5 年风口——类型前 10% 达标率 科技 26.3% vs
  消费 2.3% vs 新能源 0%（5 年窗口恰是科技牛+消费/新能源熊），筛出的是风格 beta 不是
  经理能力；分桶后 S4 模拟：新进 消费 15/医药 15/新能源 6，移出 科技 26，总数持平。
  放宽到 20% 与分桶**独立**——不分桶时 p80 达标率仍是 科技 45% vs 消费 4% vs 新能源 0%，
  结构不变，白放；
- **分位人群** = 同格内净值 ≥5 年的全部池内基金（含从业 <6 年经理的基金——分位是基金级
  质量指标，与经理从业无关）；
- 超额基准 = 类型合成（股指权重 90/70/50/50，华泰口径，平衡型 50/50 为估设：沪深300 价格指数 + 中债新综合财富）。
  **同类内基准统一 → 超额排序 ≡ 原始收益排序**，闸按超额实现（数学上即收益排序），超额列仅展示；
  沪深300 未计约 2%/年股息，只影响超额绝对值、不影响同类内排序；
- 经理以 (姓名, 公司) 为键聚合（mgr_em 行级配对，天然无重名歧义）；任本基金年限自 F10 上任日起算
  （与债券池 S3 同源，含回归接管修正）；**数据不足不猜测**——pair 缺从业/上任日即剔除并计入漏斗。

> 新任经理（<1 年）不背前任战绩——复用 `data.py` 已有的上任日修正逻辑。
> **v1 实现**：`fundscorer/eqgate.py`（`python -m fundscorer.eqgate`）+ `tests/test_eqgate.py`（9 契约测试）；
> 输出 `data/eq_gate_{managers,funds}.csv` + `eq_gate_funnel.json`。评分/风格/展示为后续阶段（§3~§5）。

### 2.2 评分（风格子池内相对，长窗核心）

分块草案（权重全部**待回测定**，沿 docs/18 面板检验方法）：

| 块 | 指标 | 依据 |
|---|---|---|
| A 超额持续性（核心） | 长窗年化超额、季度超额胜率、季度超额标准差 | 且慢框架：持续+稳定两大问题 |
| B 能力质量 | 选股能力（T-M 或简化代理）、**风格/行业稳定性**（§5） | 华泰回测：选股能力是唯一长期稳定有效因子；稳定性是本模块特色闸/分 |
| C 质地 | 从业年限、任本基金时长、规模适度 | 华泰定性 5 指标精简 |
| D 风险哨兵 | 近 5 年最大回撤/波动 → **只做闸与展示，不做主排序** | docs/18 §2 结论 |

**短窗（近 1 年）业绩不进评分**，只进 §3 的阀逻辑与展示提示。

### 2.3 优秀经理阀（用户要求①）

双窗口制：

- **长窗（定级窗）**：近 3 年（占位；§9-3），决定经理的等级与是否获阀；
- **短窗（观察窗）**：近 1 年，只产生提示，不产生降级。

**阀的定义（草案，阈值占位）**：

```
长窗优秀 = 年化超额 > 0 且 季度超额胜率 ≥ X% 且 风格/行业稳定性 ≥ Y 且 长窗完整 ≥ 3 年
获阀后   → 近 1 年跑输不降级、不剔除，展示标「逆风期」标签（含跑输幅度）
未获阀   → 近 1 年表现照常参与降级/剔除
```

> 与固收+ R3 精英经理闸同语义（docs/12/18：允许优秀经理一年失手），但方向相反的应用：R3 是"长期达标放宽风险闸"，本阀是"长期达标豁免短期跑输降级"。**阀的阈值 X/Y 必须用面板回测验证"获阀者次年确实大概率恢复"再定**，否则就是拍脑袋放水。

**上限约束**：豁免只免"降级"，不免"展示近 1 年跑输事实"——避免变成变相荐基。

## 3. 风格分池：成长 / 价值 / 均衡（用户要求②）

### 3.1 为什么要子池内评分

风格是 A 股最大的周期来源：成长连涨两年时，价值经理长窗数据天然难看。若全池混排，等于让价值经理在自己的逆风期被系统性错杀。**评分、排名、阀的判定全部在风格子池内进行**，沿用本仓库"池内相对评分、不同池不可横比"的既有口径——风格子池是"池"的下一级，同样适用该声明。

### 3.2 判定方法（推荐：净值回归，v1 落地）

| 方案 | 原理 | 优缺点 |
|---|---|---|
| **A 净值风格回归（推荐 v1）** | 用复权净值对 4 条风格指数（大盘价值/大盘成长/小盘价值/小盘成长）滚动回归，取暴露向量 → 归类 | 数据全部已有（净值）；华泰同款；缺点：受贝塔与行情噪声影响，需平滑 |
| B 持仓估值法 | 重仓股 PE/PB 分位 → 价值/成长 | 直观，但依赖持仓抓取（§7 新增工程）与个股估值源 |
| C 第三方标签 | 直接取平台风格标签 | 零成本，但口径黑箱、不透明，不利合规说明 |

**归类规则（草案）**：滚动 1 年（占位）暴露向量 → 价值暴露显著 > 成长 → 价值池；反之成长池；两者皆不显著或双高 → 均衡池。**经理风格取其在管产品暴露的加权合成**（管理时长加权，沿华泰做法，不用规模加权——规模与业绩相关会引入偏差）。

- 风格判定结果**每季随周更复核**，经理可在池间迁移（迁移历史留痕，展示"2025Q1 由价值转均衡"类记录，防止单季噪声来回跳）。
- 需新增数据：4 条风格指数净值（天天基金/中证指数，周更拉取，量极小）。现有指数池是否已含价值/成长标的 → 落地前核查（§7）。

### 3.3 展示分组

榜单按三个风格页签分组：**成长 | 价值 | 均衡**。不提供跨风格总榜（防止不可比分数被并排）；如需全景，只给"各风格 top 名单"聚合视图，明确标注不可横比。

## 5. 风格稳定性评估（用户要求③）

针对两种漂移，分别设防：

### 5.1 风格漂移（价值 → 追涨成长）

- **指标**：滚动暴露向量的时序波动（华泰"风格波动率"同款）+ 与自称风格的偏离度；
- **判定（草案）**：连续 N 个季度（占位 4）第一暴露方向与池别不一致 → 触发漂移标记；
- **处理**：稳定性块扣分 + 展示「风格漂移」标记；连续 ≥6 个季度 → **迁池**（按新风格重新归类，而不是留在原池扣分——他已经变成另一种经理了）。

### 5.2 行业漂移（医药 → 追科技）

- **数据**：季报**行业配置**（东财持仓页行业段优先，前十大重仓兜底，§7）；
- **指标**：第一大行业占比时序 + 行业集中度 + 新进行业与历史能力圈的重合度；
- **判定（草案）**：历史能力圈行业（曾连续 ≥4 个季度占比 ≥20%，占位）在近 N 个季度全部退出前二、且新第一大行业与历史能力圈零重合 → 追涨漂移标记；
- **处理**：同 5.1（扣分 + 标记 + 极端情况迁池/除名）。

### 5.3 防误伤

- **调仓 ≠ 漂移**：单季波动不触发，必须"连续 N 季度"才判定；
- **正常进化不惩罚**：基金经理扩大能力圈（新行业先小仓位试水、逐步加仓）与"弃旧追新"的区分 = 旧行业是否被**清仓式**退出；
- 判定窗口与参数全部占位，**须面板回测验证"漂移标记者次年确实更差"**（否则标记无意义）。
