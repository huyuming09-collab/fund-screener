## 3. 核验副产物（实证暴露的新问题）

### 3.1 经理块反向 IC（最重要新发现）
`mgr_tenure` 两池反向且显著（2y 口径更甚：短 −0.194/t −6.0，长 −0.138/t −6.5）。设计上经理块
（4+5+11=20 分）为固定配额直觉块，但其两个可回溯子项的 IC 均不支持"任期越长越好"。
候选解释：长任期与"风格固化/船大难掉头"相关；S3 闸（≥3 年）已保证最低任期，评分再给正权存在**边际冗余甚至反作用**。
处理路径（D16）：a 维持固定块（承认直觉优先，接受证据反驳）；b 经理块降额+转 IC 池按池重分配；c tenure/career 转反向（不建议，因果存疑）。

### 3.2 短债月度胜率负 IC
见 §2。0.46 → 0 的改动会引发短债榜微变，需零位移 diff 评估（D10）。

### 3.3 docs/05 悬空引用
`docs/05-历史回测因素分析.md` 在 e1b9d88（公开仓内容优化）中被删除，但 `config.py`/`backtest.py`/docs/01/12/13 仍引用它。证据本体未丢（`data/backtest_panel.pkl`、`backtest_ic.csv`、`backtest_ic_nodes.csv`、`backtest_quintile*.csv`、`backtest_obj_*.json` + `backtest.py` 文首口径）。处置：docs/13 §8 已注；长期建议恢复一个精简版证据文档（或把本文档 §2 视为权威入口）。

### 3.4 fee 方向待复核
短债 fee raw IC +0.309 与"低费率好"的设计方向相反（长债 +0.100 同号更弱）。回测权重路径对 IC 乘方向（backtest.py:416），但 CSV 存的是 raw——需确认 CSV 口径后复核：若 raw 口径成立，说明 2022 后节点上"低费好"可能失效（费率与管理能力正相关的幸存者效应）。列 P2 复核项，暂不动权重。

## 5. 变更纪律

任何权重/阈值/闸改动 = 产品决策，须用户逐项确认；改动后强制流程：
基线（pytest 226 / SMOKE）→ 管线重跑 → 三池零位移 diff（对外池逐位比对）→ STATUS §1/§6 同步 → 分步提交。
