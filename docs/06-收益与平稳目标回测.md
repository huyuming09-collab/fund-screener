# 目标函数回测：追求"收益更高 + 曲线平稳"的最佳评价指标

> 日期：2026-10-15 ｜ 引擎：`fundscorer/backtest2.py` ｜ 面板：17,222 基金节点 × 2,769 只基金
> 前置文档：`docs/05-历史回测因素分析.md`（目标=跑赢中位胜率）；本文换目标为**风险调整后收益**
> 数据文件：`data/backtest_obj_nodes.csv`（逐节点）、`data/backtest_obj_weights.json`（候选权重）、`data/backtest_obj_decision.json`（决策）

## 一、这次与 docs/05 的本质区别

用户目标变了：**不追求"跑赢 90% 同类"，追求"收益尽可能高，同时曲线平稳"**。
docs/05 的目标函数（跑赢同池中位的胜率）无法刻画"平稳"，因此重建面板，直接观测**前瞻风险**：

- `fwd_mdd_1y`：T 之后 1 年内的实际最大回撤（含 T 点净值为起点）
- `fwd_vol_1y`：持有窗口内实际年化波动

全样本前瞻 1 年：回撤中位 **1.42%**、均值 3.00%；波动中位 1.37%（债券基金量级合理）。

## 二、方法（预注册，防事后挑指标）

**候选目标函数**（前瞻 1 年，均转为"越大越好"）：

| 代号 | 定义 | 含义 |
|---|---|---|
| ret | 收益 | 纯收益，不控回撤 |
| calmar | 收益 / max(回撤, 0.5%) | 收益回撤比 |
| u1/u2/u3 | 收益 − λ×回撤, λ=1/2/3 | 多担 1% 回撤须多赚 λ% 收益 |
| uvol2 | 收益 − 2×波动 | 对波动付费 |

**候选方案**（训练段 7 节点定权重，验证段 4 节点检验，IC 全部方向对齐，打分复用生产 `_score_one` 含红线封顶）：
S0=现行 v5.1 ｜ S_pool=全池等权基线 ｜ S1~S5=对各目标的纯 IC 权重 ｜ S6=混合B(u2) ｜ S7=S1 分数+事前平滑过滤（T 时波动与回撤均≤池均值×1.5）

**★ 预注册决策规则**（写死在模块头部，先于运行）：
> 验证段中 实现 u2 均值最高、且平均前瞻回撤 ≤ S0 的方案为"最佳"。

## 三、核心发现

### 3.1 因子对"未来曲线平稳度"的预测力（训练段 IC，方向对齐）

**固收+池是问题所在**：`ret_1y` 预测未来收益（IC +0.27），但**同时预测未来更大的回撤**（对 −回撤 的 IC −0.36）——追动量 = 买高波动 = 曲线变差。而 `mdd_1y` 对未来回撤的 IC 高达 **+0.72**、`vol_5y` +0.70：**风险类因子对"未来平稳"的预测力远强于对"未来收益"的预测力**。

纯债两池方向相反：未来回撤本就极小（中位 0.3%~0.9%），calmar 目标的最优权重仍落在 低费率+收益持续性 族（fee/ret_3y/lvi/winrate）——与 v5.1 同族，差异小。

### 3.2 组合验证（前 20% 组合的前瞻表现，各池平均）

| 方案 | 训练段 | 验证段 |
|---|---|---|
| | ret / mdd / **u2** | ret / mdd / **u2** / calmar |
| S0 现行 v5.1 | 3.78% / 2.15% / −0.52 | 3.60% / 1.17% / +1.26 / 4.57 |
| S_pool 全池等权 | 3.41% / 2.31% / −1.20 | 3.34% / 1.90% / −0.46 / 4.28 |
| **S2 = IC(calmar)** | 3.65% / 1.63% / **+0.40** | **3.68% / 0.85% / +1.98 / 4.93** |
| S3 = IC(u1) | 3.72% / 1.70% / +0.31 | 3.69% / 0.87% / +1.94 / 4.92 |
| S7 = S1+平滑过滤 | 3.90% / 2.09% / −0.28 | 3.68% / 0.92% / +1.84 / 4.84 |

（u2 = 收益−2×回撤，% ；calmar = 收益/回撤）

**★ 预注册规则选出 S2**。验证段相对现行：**回撤 −27%（1.17%→0.85%）、收益 +0.08pp、u2 +57%**。
稳健性：λ 家族（calmar/u1/u2/u3 = 1.98/1.94/1.51/1.48）全部 ≥ 现行 1.26——结论不依赖 λ 的选择。

### 3.3 改进来自哪里（逐节点核查）

| 池 | u2 逐点胜 S0 | 回撤更小 | 验证段 u2 变化 |
|---|---|---|---|
| 短债 | 7/11 | 7/11 | 2.37% → 2.42%（差异噪声级） |
| 中长期 | 7/11 | 9/11 | 2.66% → 2.67%（差异噪声级） |
| **固收+** | **10/11** | **11/11** | **−1.26% → +0.86%（翻正）** |

**改进几乎全部来自固收+池**，且 4 个验证节点方向完全一致（2022H2 −2.30→+0.38 / 2023H1 −3.19→+0.17 / 2023H2 +0.42→+1.89 / 2024H1 +0.01→+0.99），不是单一时点运气。
纯债两池未来回撤已经很小（0.3%~0.8%），"平稳"维度在该两池几乎无区分度——S2 与其差异属噪声。

### 3.4 S2 权重 vs 现行（固收+池，回测可回溯子集合计 88）

| 因子 | 现行 v5.1 | S2=IC(calmar) |
|---|---|---|
| mdd_1y | 2.0 | **23.4** |
| vol_5y | 2.0 | **20.7** |
| mdd_3y | 3.0 | **19.1** |
| mdd_5y | 7.0 | **14.2** |
| mgr_tenure | 4.0 | 7.9 |
| ret_1y | 24.2 | 2.8 |
| age / lvi_3y / 其余 | 16.9 / 15.9 / … | 全部 ≈0 |

**v5.1 在固收+池押 24 分动量（ret_1y）+17 分年龄，正是"曲线不稳"的来源**；S2 把约 77 分给风险因子（在生产中仍按门槛式打分：≤池均值×1.5 满分）。

### 3.5 诚实披露：top10hit 没有提升

进同池前 10% 的概率：S0 验证段 **8.1%**、S2 **8.7%**（随机基线 10%）。
**此前我预估 15~22%，实测低于该区间**——高波动基金占据未来收益前 10%，而任何"平稳"导向的筛选都必然放弃这部分彩票式头部。这与用户新目标一致：要的是"收益高+曲线平"，不是"押中第一名"。同时再次验证 docs/05 的结论：**不存在能大概率锁定前 10% 的评分标准**。

## 四、结论与建议

1. **最佳评价指标 = calmar（收益/回撤比）**：其 IC 权重（S2）在预注册规则下胜出，且 u1/u2/u3 家族结论一致。
2. **真正需要改的只有固收+池**：现行 v5.1 的动量集中配置在该池被证明"多赚的收益抵不上多担的回撤"；S2 使其 u2 由负翻正、回撤 11/11 节点更小。
3. **纯债两池维持 v5.1**：S2 与其差异在噪声内（回撤本就 0.3%~0.9%），不值得为微小差异重排推荐榜、增加方法变更成本。
4. **不承诺的部分**：进前 10% 概率无提升（8~9%）；固收+绝对回撤水平仍受 2021-2022 债灾节点支配（S2 在 2021H2 节点回撤仍达 9% 量级——组合层面的回撤无法靠选基消除，需仓位/分散解决）。

### 建议采纳方案（v5.2，**用户已于 2026-10-15 确认采纳**）

仅替换 `FIXED_PLUS_WEIGHTS` 的可回溯部分为 S2（合计 88），保留不可回溯的 mgr_products_ann 11 + ms_rating 1（数据无法回溯，沿用原值）：

```
mdd_1y 23.4 / vol_5y 20.6 / mdd_3y 19.1 / mdd_5y 14.2 / mgr_tenure 7.9 / ret_1y 2.8
mgr_products_ann 11 / ms_rating 1 / 其余 0        （合计 100）
```

纯债两池（`PURE_BOND_WEIGHTS` / `PURE_BOND_WEIGHTS_LONG`）不动。

### 局限（同 docs/05，不再展开）

幸存者偏差（历史成绩偏乐观）；窗口重叠致 t 值虚高；样本期以债牛为主，固收+的改善节点恰含 2021-2022 债灾（外推需谨慎）；候选方案集由人设计，预注册只能防"事后挑指标"、不能防"方案集遗漏"。

## 五、v5.2 上线后全市场重跑的副作用观察（2026-10-15，run10）

**改动隔离验证 ✓**：短债/中长期两池分数与 run9 逐位一致（007194=85.53、006980=86.49，5★ 数 8/22 不变）；110017 固收+ 89.97→96.43（16→18 名，系全池分数普涨，仍 5★）。

**副作用 1（预存在，v5.2 在固收+放大）：<1 年新基金冲进推荐榜前三。**
固收+ top-20 含 3 只不足 1 年的新基金（027692 #2 / 027005 #3 / 027008 #8，得分 98.15/98.15/97.61，
nav 0.33/0.48/0.39 年，均带 `insufficient_history 未满1年不入池/不评星` 标记，LVI −1.70/−1.69/−4.17）。
- 成因：回测面板要求节点处 ≥3 年历史，**回测从未验证过短历史基金**；v5.2 把 age 16.91→0（v5.1 的年龄分无意中充当了新基金抑制器），
  同时风险块 19→77.3，而平静市况下 4 个月净值的回撤/波动几乎必然拿满分 → 短历史基金总分 98+。
- 这是**预存在问题**：v5.1（run9）短债池第 9 名 020807 成立仅 0.61 年同样无星入榜；docs/01 规则 R2 写明"<1 年不入池"，
  但实现只做了"不评星"，361 只 <1 年基金仍在评分池内参与 percentile 同伴比较（文档与实现不一致）。

**副作用 2（校准漂移，非错误）：固收+星级由配额而非质量约束。**
≥85 分基金从约 50 只 → **644 只**，5★ 从 50 → **230**（配额 cap=floor(2963×10%)=296，其中 66 个名额被 1~3 年基金占用后按 R2 清星）。
门槛式风险打分使 77.3 分块几乎人人近满分，分数分布整体上移、区分度移出风险块转入经理块。
配额机制（≤10%）正常兜底，5★ 占池 6.9%，**无需修复，但"85 分"在固收+已不再意味着绝对质量**。

**处置（2026-10-15 用户确认：榜单只出 ≥3 年基金）**：
- `rank.py` 推荐榜过滤 `star` 非空（= 满 3 年，回测验证域内），头部打印各池"可入榜 n / <3年 m 不入榜"；
- `full_report.csv` 新增 `in_board` 列（是/否），<3 年基金**仍完整打分展示**，不删数据；
- 处置后三池 top-20 均无短历史基金（固收+ top-20 最低成立 3.4 年）；纯债两池分数逐位不变。
- 遗留一致性问题（未修，记录）：规则 R2"<1 年不入池"的实现仍是"只评星不评分池"，
  361 只 <1 年基金仍参与 percentile 同伴比较——影响极小（<1 年基金的分位贡献稀释），
  若要彻底对齐需重建评分池，留待下次数据迭代。
