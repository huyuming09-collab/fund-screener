# 三池基金筛选与评分体系说明书（外部评审稿）

> 版本口径：2026-10-18 生成，榜单数据为 **2026-10-17 收盘**全量刷新结果。
> 本文档为自包含评审材料：不引用任何外部文档，所有规则、阈值、口径与当前榜单数据均在此文内。
> 评审对象：一个面向个人投资者的中国公募基金周更榜单系统（短债 / 中长期纯债 / 固收+ 三个池，各出 TOP20）。

---

## 0. 产品口径与评审邀请

**产品目标**：按三类资金人群提供周更基金榜单：

| 池 | 目标人群 | 目标函数 |
|---|---|---|
| 短债池 | 短期资金，几乎不承担风险 | 极致稳定，收益作为次要排序项 |
| 中长期纯债池 | 较长期资金，愿承担稍高波动，稳定性优先 | 稳为底、稍偏收益 |
| 固收+池 | 超长期资金，可承受个位数回撤，要求收益明显高于前两者 | 风险预算内选卡玛（收益/回撤比）最优 |

**请评审者批判性评估**：① 池划分逻辑是否有硬伤；② 筛选阈值的统计合理性；③ 评分卡权重与打分机制是否与其宣称的目标函数一致；④ 当前榜单是否存在明显的不合理入选；⑤ 统计陷阱（前视偏差、幸存者偏差、多重检验等）；⑥ 投资者适当性与表述合规风险。

## 1. 数据口径

### 1.1 数据源与刷新

- 数据源：天天基金公开数据——日频复权净值、F10 基金概况（类型/经理/费率/规模）、基金公司非货规模、晨星评级。无持仓明细数据（股票/转债仓位不可直接观测）。
- 刷新节奏：每周五 23:00 全量刷新三池（约 6300 个份额），重算全部指标、重筛、重评、重排。

### 1.2 全集构建与排除

- 全市场债券/混合基金约 7580 只 → 排除封闭式/定期开放式 1315 只（流动性考虑）→ 排除基金公司非货规模 <300 亿元的公司旗下产品 890 只（"小公司风险大"口径；无公司映射或规模数据的**保留**，不冤枉排除）。

### 1.3 份额合并（基金级口径）

同一只基金的 A/B/C/D 等份额合并为一条基金级记录：

- 代表份额 = 规模最大份额（其经理视为本基金现任经理）；
- 经理从业年限 / 本基金任职年限 = 同现任经理全部份额中的**最大值**；
- 业绩指标 = 历史最久份额（并列时优先 A 类）；
- 合并规模 = 全份额规模合计；
- 榜单呈现与排序取 **A 类份额**的分数（无 A 类则用代表份额）。

### 1.4 指标定义（近 5 年窗口，除注明外）

| 指标 | 定义 |
|---|---|
| ret_Ny | 近 N 年年化收益（复利口径，252 交易日） |
| mdd_Ny | 近 N 年最大回撤（区间净值相对历史高点最大跌幅，正数） |
| vol_Ny | 近 N 年日收益标准差 × √252 |
| winrate_m_5y | 近 5 年**月度收益为正**的占比（对 0，非对基准） |
| q_win_20q | 近 5 年**正收益季度**占比 |
| q_excess_20q | 近 5 年**跑赢基准**的季度占比（基准见 1.5） |
| yearly | 近 5 年各完整自然年收益率 |
| excess_5y | 近 5 年年化 − 基准同期年化 |
| lvi_5y | 长期性价比指数 = 超额收益 ÷ (0.6×最大回撤 + 0.4×下行波动) |
| fee_total | 管理费 + 托管费 + 销售服务费（代表份额，年费率；不含申购/赎回费） |
| mgr_tenure | 现任经理任本基金天数；mgr_career 经理从业年限；mgr_products_ann 经理职业生涯全部产品（剔任职<2年产品与货币基金）任职年化的**中位数** |
| inst_ratio | 机构持有占比 |
| 修复天数 | 最大回撤后净值回到前高所需交易日；无显著回撤（回撤 < 池别下限：短债0.15%/长债0.5%/固收+3%）则按成立年限折扣给满 |

### 1.5 基准口径（评审请注意此简化）

- 统一用**中债综合财富指数**（全久期债券指数）作为基准代理（短债池用 1 年以下短端债券指数代理）；未按各基金合同基准逐只取数。
- 因此固收+ 池的"超额收益/跑赢季度占比"系统性低估权益部分的贡献——该两项在固收+ 评分卡中权重为 0，仅在纯债评分卡中使用。

### 1.6 分位与打分基础

- 所有池内分位均以**该池筛选前的全池**（份额级）为基准，缩尾（1%/99%）后转 0~100 分位分，逆向指标取 100−p。
- 数据清洗：单日 |收益率| > 20% 判为数据坏点并中和（公开数据偶发跳变如 +134%）。

## 2. 池划分规则

按基金类型文本与行为依次判定（先到先得）：

1. 类型含"混合"且含"债券"（债券型-混合一级/二级，即可转债增强型债基）→ **固收+**；
2. 类型含"混合"或"偏债"或"灵活"（混合型-偏债/灵活等）：
   - 业绩基准含股指成分（沪深300/中证/上证综指/创业板/恒生/股票）→ **固收+**；
   - 否则看行为：日收益标准差 > 0.004（约年化 6.3%）→ **固收+**，否则 → **中长期纯债**；
3. 其余（纯债型）：类型或名称含"短债/中短债" → **短债池**；其余 → **中长期纯债池**。

补充事实：债券型-混合一级中相当比例基金行为接近纯债（低转债仓位），其去留由固收+ 池的波动下限闸（S7）按行为处理，不按标签处理。

## 3. 筛选规则（三池）

### 3.1 硬条件（三池同构，S5 阈值池别化）

| 闸 | 条件 | 短债 | 中长债 | 固收+ |
|---|---|---|---|---|
| S1 | 合并规模 ≥ 5 亿元 | 5 | 5 | 5 |
| S2 | 现任经理从业 ≥ 5 年 | 5 | 5 | 5 |
| S3 | 现任经理任本基金 ≥ 1095 天（3年） | 1095 | 1095 | 1095 |
| S4 | 成立满 5 年（保证 5 年窗口数据完整） | 5 | 5 | 5 |
| S5 | 近 5 年任一单日涨幅不超过阈值（异常尖峰剔除） | **1%** | **2%** | **5%** |

S5 池别化依据：固收+ 的权益/转债单日 2%~3% 波动合法，阈值须高于纯债池防误杀；纯债池 1% 以上单日涨幅几乎必为坏数据或异常。

### 3.2 固收+专属风险预算闸（S6~S8）

| 闸 | 条件 | 设计依据（截面/前瞻证据摘要） |
|---|---|---|
| S6 | 近 5 年最大回撤 ≤ 8% | 回撤 >8% 桶前瞻卡玛崩坏（前瞻回撤中位 10%+） |
| S7 | 近 5 年年化波动 **2%~8% 双向带** | 上限 8%：>8% 桶前瞻回撤 9.17%（风险预算越界）；下限 2%：区分度闸——类型标签与行为严重交叠（债券型-混合一级中 60% 份额波动 <1.5%，行为即纯债），且中长期纯债池波动 p90=1.53%，2% 下限与之留出空隙，保证固收+ 池与前两池风险画像可区分 |
| S8 | 近五年年化 < 8% | 反追收益闸：历史高收益桶前瞻表现更差（高 β 残留）；8% 为"极端激进尾部"保险丝（历史版本为 5%，2026-10-19 放宽） |

**明确不做的事**：固收+ 不设收益下限（收益 ≥4% 的下限方案被同组前瞻数据证伪——该条件选中前瞻收益最差的桶）；不做"高收益+高胜率"技能豁免（面板检验：高收益且三信号全满的样本前瞻反而更差）。

### 3.3 性能条件（P1/P2，三池同构）

- **P1 综合分位**：近 5 年收益、近 5 年回撤、近 3 年收益、近 3 年回撤四项的池内分位求均值，再取该均值在池内的分位，要求 ≥ **45%**；
- **P2 逐年稳健**：近 5 年完整自然年（年内净值点 ≥120 且有上年基数）的**年度收益池内分位的中位数** ≥ **55%**，参与年数 ≥4，单年分位比较要求池内样本 ≥30。

## 4. 评分规则（100 分制）

### 4.1 总分机制

- 总分 = Σ(权重ᵢ × 子分ᵢ / 100)，子分 ∈ [0,100]；
- **缺失子项不计分**，总分按可得分权重等比折算到 100 分（earned_weight 归一）；
- 红线触发（R7）总分封顶 60。

### 4.2 子分三类机制

1. **池内分位型**（收益族/胜率族/费率/经理产品年化等）：全池缩尾分位，逆向指标取 100−p；
2. **门槛型**（纯债池的 mdd/vol）：≤ 池均值 × 1.5 给满分，≥ 池均值 × 4 归零，中间线性（"够稳即满分，不过度区分"）；
3. **绝对分档型**：
   - 固收+ 回撤阶梯：mdd_5y/3y/1y ≤ **4%** 满分，线性递减至调节上限归零（普通基金上限 10%，经理精英容差 15%）；
   - 经理本基金任职：≥5年 100 / ≥3年 70 / ≥1年 30 / 否则 0；
   - 经理从业：≥8年 100 / ≥5年 70 / ≥3年 40 / 否则 0；
   - 费率：池内分位（越低越好）；
   - 逐年表现（纯债 yearly_5y）：每年为正且 ≥ 池中位记 2 分、为正但低于中位记 1.2 分、非正记 0 分，按可得年份折算；
   - 机构占比：20%~90% 满分，>90% 记 0，10%~20% 记 50，<10% 记 30（**注：该因子在固收+ 权重表中权重为 0**）；
   - 晨星评级：5星 100 / 4星 80 / 3星 60 / 2星 40 / 1星 20，缺失 50。

### 4.3 固收+经理资质容差（R3）

- 判定：任职期内**每一年**收益被池内超过比例 ≤50%（前半）且**平均**被超过比例 ≤33.3%（前 1/3），可比年数 ≥3 → 经理精英；
- 效果：回撤阶梯的归零上限由 10% 放宽至 15%（仅影响 3 年/1 年回撤在 10%~15% 区间的评分；5 年回撤已被 S6 闸在 8% 内）；
- 历史注记：2026-10-19 修复过一次方向反转 bug（阈值语义为"被超过比例"，原实现直接拿收益分位比较导致垫底经理拿容差）；修复后固收+候选中约 24% 判定为精英。

### 4.5 红线（R7，触发总分封顶 60）

1. 现任经理任职 < 180 天；
2. 规模 < 5000 万；
3. 近 1 年回撤双条件（相对池中位超额回撤超阈值：短债 0.3% / 长债 1.5% / 固收+ 用调节后上限）；
4. 近 1 年存在单日异常跌幅（> max(3×日常中位振幅, 池别绝对下限：0.10%/0.30%/1.5%)）且 20 个交易日内未修复一半；
5. （固收+）显著回撤超 240 个交易日未修复。

### 4.6 星级

分数 ≥85 → 5 星（占池比例上限 10%）；≥75 → 4 星（上限 25%）；≥60 → 3 星；≥45 → 2 星；其余 1 星。

## 6. 系统运行口径与已知事实性限制

3. 评分中的池内分位基准为**筛选前全池**（含后续被筛选闸剔除的基金）。
4. 三池各自独立分位、独立评分，分数跨池不可比；星级配额按池独立。
5. 榜单每周五更新，非实时；持有期限制（如"6 个月持有期"）体现在基金名称中，未单独结构化提示。
6. 费率口径为管理+托管+销售服务费（代表份额），不含申购费与赎回费。
7. 免责声明：榜单为公开数据整理与量化筛选结果，不构成投资建议；历史表现不代表未来。
