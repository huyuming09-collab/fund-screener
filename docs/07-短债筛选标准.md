# 07 · 短债筛选标准（先筛后评）

> 版本：v1.1（2026-10-15 基金级口径修订） · 实现：`fundscorer/screen.py` · 参数：`fundscorer/config.py → SCREEN`
> 定位：**只做短债**的两段式筛选——先按用户指定的硬条件+性能条件筛出候选，再按 v5.2 全市场分数排序。
> 评分模型本身不变（v5.2，见 05/06），本文件只定义"筛哪些"和"怎么排"。
> v1.0→v1.1：份额合并由"代表份额口径"改为**基金级口径**（用户确认），
> 并修复审计发现的从业年限重名误配、A/B 份额识别两处缺陷（见 §八）。

## 一、用户原始口径（2026-10-15）

> 先筛选，对符合条件的基金再进行评分排序：
> 1. 基金规模 **5 亿以上**（同一基金不同类型如 ABCD 等**合并计算**，不分开单独计算）；
> 2. 基金经理**从业 5 年以上**；
> 3. 当前基金经理**管理该基金 3 年以上**；
> 4. 年化收益和回撤，近五年和近三年数据都应处于**同类前 40%**；
> 5. 每一年的数据都应**优于 55% 同类**（避免某一年踩风口涨幅过多，属偶然因素）；
> 6. 剔除**异常涨幅**（部分基金一天内涨好几个点，需排除）。
>
> 补充：如果交集为空，可适当放宽标准，保证最后筛选出来**够 20 支**即可。

其中第 4、5 条按字面阈值（前 40%、每年 >55%）在短债全池**任意阈值组合下交集为空**（详见 §4），
故按用户授权放宽为"方案甲"，并经用户确认。

## 二、两段式流程

```
短债全池 1161 份额
   │  份额合并（基础名归并，基金级口径）→ 482 只基金
   ▼
【阶段一 · 硬条件 S1~S5】
   S1 规模合并 ≥5 亿            482 → 327
   S2 经理从业 ≥5 年            327 → 266
   S3 现经理任本基金 ≥3 年      266 →  95
   S4 成立 ≥5 年（近五年数据完整）95 →  67
   S5 近 5 年无单日涨幅 >1%      67 →  65
   ▼
【阶段二 · 性能条件 P1~P2（方案甲）】
   P1 四项分位均值的池内分位 ≥45%（综合前 55%）   65 → 37
   P2 完整自然年收益分位中位数 ≥55%（≥4 个可比年） 37 → 24
   ▼
【阶段三 · 排序】
   按 v5.2 全市场分数快照（data/full_scores.json）降序
   基金分 = 其 A 类份额的 score_capped（无 A 类时用规模最大份额）
```

百分位比较基准一律为**短债合并全池 482 只**（含未过硬条件者），即"同类"= 全部短债基金，
而非仅候选子集——与干跑验证口径一致。

### 基金级口径（2026-10-15 用户确认）

同一基金的 A/B/C/D… 份额共享资产与业绩，但天天基金 F10 按**份额代码**记录经理任期，
新发大份额（如长城短债 D，2023 年成立、规模最大）的任期/年限记录短，
若直接用"规模最大份额"代表全基金会误杀（长城短债 A/C 任期 2603 天、成立 7.1 年，D 仅 1083 天、2.96 年）。故：

| 字段 | 基金级口径 |
|---|---|
| 现任经理 | 代表份额（规模最大）所记经理 |
| 经理从业 / 任本基金任期 | **同现任经理**全部份额中的最大值 |
| 成立年限 | 全部份额中的最大值 |
| 近 5y/3y 收益回撤、年度收益 | **历史最久份额**（nav_years 最大，并列优先 A 类） |
| 规模 | 全份额求和（不变） |
| S5 异常涨幅 | 全份额最大值（不变） |

经理更换场景的处理：仅现任经理（代表份额所记）名下的份额计入任期，
前任经理名下份额的长任期不借用（如富国短债 D 记刘爱民 1087 天，A/C 记张波 1227 天——两人分别计入各自的基金）。

## 三、各条件口径明细

| 条件 | 口径 | 参数（config.SCREENS["short_bond"]，别名 `config.SCREEN`） |
|---|---|---|
| 份额合并 | 基础名 = 份额名去结尾 `/X` 或大写字母后缀（`富国国有企业债债券A/B` 等，双类份额按主类 A）；基金级口径见 §二 | — |
| S1 规模 | 合并后 `scale_sum ≥ 5` 亿 | `scale_min_yi=5.0` |
| S2 从业 | 同现任经理全部份额 `mgr_career_years` 最大值 ≥ 5（按基金代码消歧重名经理，见 §八） | `mgr_career_min_years=5.0` |
| S3 任期 | 同现任经理全部份额 `mgr_tenure_days` 最大值 ≥ 1095（3 年） | `mgr_tenure_min_days=1095` |
| S4 成立 | 全份额 `nav_years` 最大值 ≥ 5，保证近五年收益/回撤数据完整 | `min_nav_years=5.0` |
| S5 异常涨幅 | **全局窗口**：净值日期 > `今天−5年` 的区间内，任一**份额**单日复权净值涨幅（`pct_change`）> 1% 即剔除；取该基金所有份额的最大值；无净值数据 = 无法验证 = **不放行** | `spike_max_gain=0.01` |
| P1 综合 | 四项分位（历史最久份额口径的 `ret_5y↑ mdd_5y↓ ret_3y↑ mdd_3y↓`，全池 rank pct）→ 均值 `mean4` → `mean4` 在池内的分位 `mpct ≥ 0.45` | `comp_pct_min=0.45` |
| P2 年度 | 历史最久份额净值的近 5 个**完整自然年**（今年不计；年内净值点 ≥120 且存在上年基数才计入）各年收益在池内的分位，取**中位数 ≥ 0.55**；可比完整年 <4 直接不通过 | `yearly_median_min=0.55`、`yearly_min_years=4`、`yearly_min_obs=120`、`yearly_pool_min=30` |
| 排序 | `full_scores.json` 中 A 类份额（含 A/B 双类）`score_capped` 降序；无 A 类→代表份额→任一有分份额 | `prefer_letter="A"` |

### S5 关于"近 5 年"窗口

- 窗口为**全局锚点**（所有基金统一 `今天−5年`，当前 = 2021-10-15 起），不是"各基金数据截止日−5年"。
  已用 1161 个份额逐一比对，全局锚点与研究口径 0 差异；按各基金自身截止日算会有 1 例不一致。
- 只看**涨幅**，不看跌幅（用户口径为"异常涨幅"）。
- 1% 是"好多个点"的保守量化：14 只基金（2.9%）因近 5 年内单日 >1% 被剔除。

### P2 关于"完整自然年"

- 判定：该年净值点 ≥120 **且** 该年之前已有净值（成立当年无上年基数，不算完整年）。
- 已验证：此规则与研究口径 482/482 完全一致；只用"≥120 点"会有 120 只不一致（缺"上年基数"条件所致）。
- 用**中位数**而非"每年都要 ≥55%"：用户意图是排除"某一年踩风口"的偶然性，中位数同样剔除单年异常拉动，
  但避免因 2021 年短债债灾等系统性年份把全部候选杀空。

## 四、放宽决策记录（为什么不是字面的前 40%）

字面规则 = [近5y/3y 收益与回撤四项都进前 40%] × [每年收益都 >55% 同类]。
在 482 只全池上扫描：四项全前 40% 最多 13 只，且逐年条件再筛后**交集恒为空**——
瓶颈在于两项条件各自能通过的基金几乎不重叠（严条件各自通过率都低，乘积为空）。
故按用户"交集为空可放宽、保证 ≥20 支"的授权，采用**方案甲**（已确认）：

| 项 | 字面规则 | 方案甲（现行） |
|---|---|---|
| P1 | 四项**各自**前 40% | 四项分位**均值**的池内分位 ≥45%（综合前 55%） |
| P2 | **每一年**都 >55% | 各年分位的**中位数** ≥55%（可比年 ≥4） |
| 结果 | 空集 | **24 只**（2026-10-15 基金级口径数据，满足"够 20 支"） |

方案甲的 24 只满足用户"够 20 支"的要求；两项放宽都是"从逐项硬门槛 → 集中趋势门槛"，
仍保留"整体靠前 + 无单年异常"的原意。

## 五、排序口径（已确认）

- **排序分 = 全市场 v5.2 分数**（`data/full_scores.json` 的 `score_capped`），不在幸存者内部重算、不重排百分位。
- **基金分 = 其 A 类份额的分数**（用户确认"按照A类排序"；A/B 双类份额按 A 计）。24 只全部含 A 类，`score_source` 全为 "A类"。
- 这一口径下排序与"按代表份额（规模最大）排序"可能不同（A/C 份额分数差异可达 10+ 分、名次差 12 位），
  例：兴业60天 A 类 84.5 而其最大规模份额为 C 类 72.1；国泰利泽90天 A 类 71.2 而 C 类 55.6。
- 榜单同时输出 `share_scores`（全部份额分数）与 `src_name`（业绩口径份额）便于人工复核。


## 七、边界与诚实披露

- **两段独立**：筛选不改变评分；通过筛选 ≠ 高分，排序只在候选内部比 v5.2 分。
- **S5 数据不足不放行**：无净值文件的份额无法验证异常涨幅 → 视为不通过（当前数据 0 例）。
- **百分位基准是短债全池**，不是"剔除硬条件后的候选池"——避免幸存者偏差被二次放大。
- **经理更换**：仅现任经理（代表份额所记）名下份额的任期计入 S3；前任经理长任期不借用。
- **重名经理无法消歧时**（按基金代码在经理表查无且姓名重名）从业年限记 None → S2 不放行（短债池当前 0 例）。
- 本工具不保证跑赢任何基准；价值在于提高风险调整后收益与剔除明显异常项。
- 金牛奖仍为永久搁置项（见 06）；R2 相关不一致已记录于 06 §五。

## 八、审计记录（2026-10-15，v1.0→v1.1）

用户要求"统一处理"的全面审计，共发现并处理 5 类问题：

| # | 问题 | 影响 | 处理 |
|---|---|---|---|
| 1 | **代表份额口径缺陷**（主问题）：S2/S3/S4/业绩取"规模最大份额"，新发大份额（长城短债 D 等）任期/年限短被误杀 | 12 只 S3 误杀、22 只 S4 误杀 | 改基金级口径（§二），漏斗 87→95、59→67，最终 20→24 只 |
| 2 | **经理从业年限重名误配**：`fetch_manager_career_years` 仅按姓名查经理表取首行，全市场重名 3911 人（"刘杰"61 个），114 条取错（短债池 26 条），5 只基金 S2 判定翻转 | 富国国有企业债/富国安利 90 天从业被记 1.2 年（实际 8.7 年）等 | 改为按"现任基金代码"精确定位；代码查无且重名 → None 不放行；缓存已 patch（145 条变更） |
| 3 | **A/B 双类份额识别**：`share_letter("富国国有企业债债券A/B")` 返回 'B'，A 类排序偏好失效 | 2 只基金（富国国有企业债、交银双轮动） | 正则改为双类整体匹配返回主类 'A' |
| 4 | **净值停更份额**：3 个份额净值停更 >90 天（004638 华夏鼎兴C 停更于 2021-11、531030 建信周盈B、025819 博时裕发C），均为规模 0.0 的终止份额 | 其所在基金的份额合并/年度口径可能受污染 | 基金级口径下"历史最久份额"自动避开停更的年轻份额；3 只问题份额所在基金均未入选，无实际影响，暂不额外处理 |
| 5 | **经理表无唯一姓名**：经理表按姓名查询天然不安全（6293 条记录 0 条姓名唯一） | 隐性数据风险 | 同 #2，统一按代码消歧 |

审计中排除的非问题（已验证无需处理）：

- 8 组"同基金不同份额经理不同"为真实经理更换/共管，非合并错误（基金级口径已按现任经理处理）；
- 成立日期跨度大的组（汇丰晋信平稳增利 15.4 年等）为真实的分批增设份额，非误合并；
- 全部 24 只候选的 A 类份额在快照中均有分数；净值新鲜度 1~2 天，无停更风险；
- 无后缀名称（中银安心回报等 9 只）均为单份额基金，无合并歧义；
- 缓存新鲜度抽检 40/40 一致，metrics_cache 与 nav_full 对齐。
