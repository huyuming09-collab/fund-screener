# 13 · 短债/长债两池筛选与评分规则（债指添加改造基线）

> **用途**：为「债券指数基金（下称债指）加入短债/长债榜」的规则修改提供**现状基线**：
> 规则全量快照 → 逐条指数适配分析 → 待拍板清单 → 验证清单。
> 规则/阈值/权重任何改动均属产品决策（AGENTS §7），落地前须用户确认。
> **数值基准**：v5.8 代码（`fundscorer/`，2026-10-20）；文中漏斗实例为 2026-10-20 实测（`metrics_cache` 口径，`load_screen_inputs(asof=None)`）。
> **口径纪律**：两池分数均为**池内相对评分**，不同池不可横向比较；所有 `*_5y` 指标均已过「成立满 5 年」闸（S4），债指侧另有 3 年口径（见 §0/§4）。

## 0. 开关现状与边界

- 对外发榜池：中短债、长债（固收+ 于 2026-10-20 解锁）。**债指未启用**：
  `config.INDEX["enabled"] = False`（2026-10-19 用户决议先剔除，决策留档 `docs/11-三池重构与指数基金口径.md §零`）。
- `INDEX` 四字段（`fundscorer/config.py:28`）：

| 字段 | 值 | 语义 |
|---|---|---|
| `enabled` | False | 总开关，唯一来源；改回 True 即恢复（勿加第二处开关） |
| `min_nav_years` | 3.0 | 指数 S4 成立年限口径（主动债基仍 5 年）——债指多为 2023 年后成立 |
| `return_metric` | `ret_3y` | 穿插排位业绩口径（用户决议：债指只看近三年）；主动侧建区间须同口径 |

- **关闭 ≠ 无代码**：指数链路已完整实现（筛选分支、独立评分与评星、穿插排位、卡片展示位）。
  `enabled=False` 时仅丢弃结果（三个关闭点见 §4.4）。改造对象是这条既有链路，不是新建。

## 1. 池定义与份额合并（两池共用，基金级口径）

入池分类：`batch.py` 按天天基金 `type_text` 归池（中短债/长债主动类 + `指数型-固收`）。
同基金 A/B/C/D… 份额在 `screen.merge_shares` 合并为基金级，规则：

| 要素 | 取数口径 | 理由 |
|---|---|---|
| 现任经理 | 规模最大份额（代表份额）所记经理 | 大份额最具代表性 |
| 经理从业/任本基金任期 | 同经理全部份额中的**最大值** | 新发大份额（如 XX 短债 D）成立晚，不能拖累全基金 |
| 成立年限 | 全部份额中的最大值 | 同上 |
| 业绩（近5y/3y 收益回撤） | **历史最久份额**（并列优先 A 类） | 长历史口径一致 |
| 年度收益 | 历史最久份额净值 | 供 P2 |

## 2. 筛选规则（`screen.screen_candidates`，两池同构、阈值池别化）

### 2.1 阈值对照（`config.SCREENS`，config.py:262/287）

| 闸 | 语义 | 中短债 | 长债 | 备注 |
|---|---|---|---|---|
| S1 | 合并规模 ≥ | 5 亿 | 5 亿 | 基金级合并规模 |
| S2 | 现任经理从业 ≥ | 5 年 | 5 年 | 指数不适用（§4.2） |
| S3 | 现经理任本基金 ≥ | 3 年（1095 天） | 3 年 | 指数不适用（§4.2） |
| S4 | 成立 ≥ | 5 年 | 5 年 | 保证近 5 年数据完整；**指数口径 3 年**（INDEX） |
| S5 | 近5年任一单日涨幅剔除线 | > 1% 剔 | > 2% 剔 | 池别化：长债久期长，>1% 占池 9.0% 且反向检验 124 件 0 反向 |
| P1 | 四项综合分位 ≥ | 45% | 45% | 见 §2.2 |
| P2 | 年度分位中位 ≥ | 55% | 55% | 见 §2.2 |

- S5 数据不足（NaN）**不放行**：无法验证"无异常涨幅"不等于通过。
- 固收+ 池另有 S6 回撤分级闸（普通 ≤10%、R3 精英 ≤12%）/ S7 波动带 2.5%~8%；S8 收益上限已删除。
  两债池**无 S6~S8**（配置键缺失即不启用）。

### 2.2 性能闸语义

- **P1**（`composite_percentiles`）：`ret_5y / mdd_5y / ret_3y / mdd_3y` 四项池内分位（回撤反向）→ 均值 `mean4` → 再取池内分位 `mpct` ≥ 45%。
  基准 = **本分支合并全池**（含未过硬闸者；主动侧 = 主动合并池，不含指数）。
- **P2**（`yearly_median_pct`）：近 5 个完整自然年收益分位的**中位数** ≥ 55%。
  - 可比完整年 ≥ 4；完整年判定：年内净值点 ≥ 120 且存在上年基数；
  - 单年分位比较的池内最少样本 30；
  - ⚠️ **基准 = `yearly` 字典全量（含指数基金，见 §4.5 口径不对称）**。

### 2.4 排序与截取

- 排序：`rank_candidates` 按 `score_capped` 降序；`prefer_letter="A"`（A 类份额优先，无 A 类用代表份额）；`TOP_N=20`。

## 3. 评分规则（v5.1 两池评分卡；`scorer.score_pool`）

### 3.1 总流程

```
指标（池内） → ① 分位/门槛/绝对分档打子项分（0~100）
             → ② 经理块子项 × 团队系数（≥2/3 名满3年共管 = 1.05/1.10，封顶 1.10）
             → ③ 加权求和 = raw_score；earned_weight = 可得分权重和
             → ④ score = raw_score × 100 / earned_weight   ← 缺失子项等比折算（R2/R5）
             → ⑤ 红线 R7 触发 → score_capped = min(score, 60)
             → ⑥ 星级配额（池 ≥20 只才评）：5星 ≥85 且 ≤池 10%；4星 ≥75 且 ≤25%；3星 ≥60；2星 ≥45
```

### 3.3 打分机制细则

- **分位因子**：`PERCENTILE_METRICS` 定方向（`ret/lvi/winrate/q_excess → higher`；`mdd/vol/rank_stab → lower`），`metrics.percentile_score` 转 0~100。
- **纯债风险块门槛制**（两债池专属，覆盖纯分位）：`mdd_5y/3y/1y、vol_5y` 若 ≤ **池均值×1.5 → 满分 100**；≥ 池均值×4.0 → 0；中间线性（`RISK_THRESHOLD`，池样本 ≥20 才启用）。"够稳即满分，超出线性扣分"。
- **repair_5y**：显著回撤按修复天数分档（`REPAIR.bands_pure`）；无显著回撤按成立年限折扣（`age_discount_cap`）。
- **yearly_5y**：逐年池内排位的绝对规则分（`_yearly_score`）。
- **质地绝对分档**（`_quality_scores`，债池旧档）：经理任期 ≥5年→100 / ≥3→70 / ≥1→30；从业 ≥8→100 / ≥5→70 / ≥3→40；晨星按星级映射；费率=池内分位（越低越好，fee_total 含销售服务费）。
- **团队系数**（v5.7）：经理块三子项分 ×coef（2 人 1.05 / 3 人 1.10，须满 3 年共管），子项分与贡献同步放大（校验行 Σ贡献×100÷载分=评分 恒成立）。
- **R3 经理资质**（`_manager_qualified`：可比年 ≥3、允许 ≤1 年跑输 >50%、平均跑输 ≤1/3）**当前仅固收+ 用**（S6 分级 + 回撤容差带）；两债池的回撤红线走 `R7-3`（`REDLINES.mdd_abs_threshold` 按池阈值，超额回撤双条件）。
- **红线 R7**（触发封顶 60 分）：R7-1 经理任职 <6 个月；R7-2 规模 <5000 万；R7-3 回撤双条件；R7-4 单日异常跌幅且 20 日未修复（R7-5 固收+ 专属）。
- **派生字段**：`calmar_5y / sharpe_5y`（无风险利率 1.5%）已计算，但两债池权重为 0（v2 因子仅固收+ 采用）。

### 3.4 展示层（不计分）

- **风格标签**（`cards._style_label`）：按本池候选的收益/波动中位切四象限（进取/稳健/防守/震荡），池内相对、仅展示。
- **对比表分块**（`cards.WEIGHT_GROUPS`）：两债池按 风险调整收益 / 稳定性 / 经理质地 三块展示。
- **星级**：配额基数 = 池内非历史不足记录数；指数侧独立配额（§4.3）。

## 4. 债指现状链路（已实现；`enabled=False` 时关闭点见 4.4）

设计决议（2026-10-19，`indexfund.py` 文首 + `docs/11 §零`）：**指数不看基金经理业绩，只看跟踪标的/业绩/费率/公司规模。**

### 4.1 归池（`batch.py`）

- `INDEX_TYPE = "指数型-固收"`（batch.py:38）；三步判池：
  ① 名称含久期（短债/中短债/1~3 年/3~5 年/5 年/7~10 年/10 年+…）→ 定案；
  ② 名称判不出 → 抓 F10 业绩比较基准复判（缓存 7 天，**仅 enabled=True 时执行**，batch.py:80 门控）；
  ③ 基准也判不出（亚债中国/信用债综合/恒定久期/区域综合等）→ 临时按长债归池以触发抓取，终判权在 classify()。
- 指数记录带 `type_text` 下传；`pipeline._is_index`（pipeline.py:192）以 `type_text startswith "指数型"` 分流。

### 4.2 筛选分支（`screen_candidates(index_fund=True)`，screen.py:252）

| 闸 | 指数侧行为 |
|---|---|
| S1 规模≥5亿 | 照跑 |
| S2/S3 经理闸 | **跳过**（漏斗键标注"S2/S3 经理闸 不适用"） |
| S4 | 用 `INDEX.min_nav_years=3`（漏斗标"指数基金口径"） |
| S5 | 照跑，阈值用**本池**池别化值（短债 1% / 长债 2%） |
| S6~S8 | 两债池无此配置键 → 不启用 |
| P1/P2 | **照跑**，但基准见 §4.5 不对称说明 |

### 4.3 评分与穿插（`pipeline._screen_pool` 步骤 4/5a + `indexfund.interleave`）

1. 指数候选**独立评分**（分位基准 = 指数子池，不与主动混池比经理指标），独立星级配额；
2. 取指数元数据 `_index_meta`：费率 `fee_total`、F10 跟踪基准 `benchmark`、公司非货规模（去重排序键 + 卡片展示）；
3. **穿插排位**（`interleave`，indexfund.py:95）：
   - 排位依据 = `ret_3y`（近 3 年）；落主动榜第 k 与 k+1 名业绩之间 → 排第 k+1；
   - **分数 = 相邻两只主动基金分数按业绩线性插值**（指数自身评分不展示为真分，`score_basis` 字段记录插值依据供卡片核对）；
   - 高于全部主动 → 排第 1（锚榜内**最高分**+ε）；低于全部 → 榜末（锚最低分−ε）；
   - **平局一律主动基金优先**（ε=1e-6 分数偏移，显示不可见）；
   - **同一跟踪指数 ≤2 只**（`per_index_max`）：`index_id` 从 F10 基准截取指数名（去现金拖累/权重/收益率/全价尾巴），优先费率低 + 公司非货规模大；基准缺失退回基金名（此时跨公司去重失效，属数据异常）。

### 4.5 已知口径不对称（改造必读）

1. **P1 vs P2 基准**：主动侧 P1 基准 = 主动合并池（不含指数），P2 基准 = 全池（**含指数**）；
   指数侧 P1 基准 = 指数子池，P2 基准 = 全池（含主动）。→ P1/P2、主动/指数四者基准互不相同。
2. **3 年筛选 vs 5 年评分**：指数 S4=3 年，但评分卡全为 5 年族因子（`ret_5y/mdd_5y/…`）。
   3~5 年新指数这些子项为 None → `earned_weight` 折算自动补分（等效经理块 20 分 + 5 年族全部白送）。
   缓解：指数真分不展示（最终分为业绩插值分，§4.3-2），折算分只影响**星级与详情指标**；
   但星级配额在指数侧独立计算，若不处理，星级会系统性虚高。
3. **排位 3 年 vs 因子 5 年**：穿插用 `ret_3y`（用户决议），筛选/评分用 5 年族——双轨并存。

## 5. 逐条适配分析（核心交付）

> 图例：✅ 直接适用 ／ 🔧 需替换或新增 ／ ⛔ 不适用 ／ ⚠️ 现状有坑
> 「拟改方向」均为**候选方案**，须用户拍板（§6）。

| # | 规则 | 主动现状 | 指数适用性 | 拟改方向 | 验证 |
|---|---|---|---|---|---|
| 1 | S1 规模≥5亿 | 基金级合并规模 | ✅ | 维持同阈值（指数小规模同样有清盘/跟踪走样风险）；或为 ETF 联接单设 | 漏斗 S1 段回核 |
| 2 | S2/S3 经理闸 | 从业≥5年/任本基金≥3年 | ⛔ | 已跳过（现决议）。替代候选：跟踪年限/跟踪误差闸——**需新数据源**（当前 F10 只有基准，无逐日净值对基准的跟踪误差） | 漏斗键标注存在 |
| 3 | S4 成立年限 | ≥5年（保 5 年族因子） | ⚠️ | 指数 3 年（INDEX）→ 与 5 年评分卡冲突（§4.5-2）。方案：a 维持 3 年+接受折算（真分不展示）；b 调回 5 年（样本锐减）；c 债指独立 3 年评分卡；d 债指不评分只穿插（=现状） | 折算分/星级分布对比 |
| 4 | S5 单日涨幅 | 短债>1%/长债>2% | ✅（同池阈值） | 拍板：是否为指数单设阈值（政金债 ETF 成分异动尖峰） | 双侧漏斗 S5 段 |
| 5 | P1 综合分位 | 主动池内分位≥45% | ⚠️ | 现状=指数子池内分位。方案：全池同池比 / 指数内比 / 取消 P1 改跟踪质量 | 分位基准回归测试 |
